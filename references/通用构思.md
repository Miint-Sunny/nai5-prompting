# 通用构思

从一句模糊的话走到一张具体分镜的**通用流程**。它跟「通用写法」是一对基准，
用动画制作的话说：**本篇是会议桌，通用写法是作画桌**——
编剧、监督、原画、摄影四个岗位先在这里轮流把**决定**做掉
（画什么故事、怎么取景、谁做什么动作、上什么光色），产出**分镜表**；
然后到写法那边**落笔**：同样这几个岗位的决定各有各的写法归宿
（对照表见文末「交棒」节），落笔用什么笔什么纸在写法开篇的语法节。
本篇可独立用于构思，不预设题材、角色或额外资料已在场。已有画面要求先保留，
缺的部分按任务意图补足；实际启用的补充说明只接管它明确规定的部分。
有运行环境 NOTE 时，语法与能力边界以 NOTE 为准。

## 先分档：用户给了多少

| 档 | 用户给了什么 | 从哪个岗位开始 | 交付 |
|---|---|---|---|
| **A 已成型** | 完整画面（谁、在哪、干什么、什么调子） | 直接进**写法层** | **1 条**。直译，不自作主张加内容 |
| **B 有主体没画面** | 「猫耳少女」 | **监督**（主体已定，补情景镜头） | **1 条**，末尾一行说明补了哪几处 |
| **C 只有方向** | 「想要点治愈系的」「有没有夏天的图」 | **编剧** | **2–3 条不同方向**，让用户挑 |
| **D 完全空白** | 「我没什么想法，按 skill 构思」 | **编剧** | **2–3 条**，至少一条走「一片空地」 |

判断很简单：**用户的话里能不能同时读出「谁」「在哪」「什么调子」三样。**
三样齐＝A；只有「谁」＝B；只有一个形容词或题材＝C；什么都没有＝D。

**用户自己说了条数就听用户的**（「给我一条就行」「多来几个」）。
话里出现「给点想法」「有什么想法」「构思」「随便来点」「**随便写点什么**」
「都行」「你决定」「自由发挥」「看着办」，一律按 C/D 走多条——
那是在要选择，不是在要答案。**首答就给成品方案**：不点评文件、不复述流程、
不先反问一轮再写。
另一个常漏的判据：**只给了 IP / 题材范围、没点名角色**（「来张明日方舟的」）
也是 C 档——给 2–3 组**不同选角**的方案，选角本身就是方向差异。

**不许空手反问。** 信息不全（没点名角色、没说清要改成什么）时，
默认动作是**先按最合理的理解给出成品**，把不确定的地方写成一行说明；
真的需要用户拍板，也**先给方案再问**，不要只回一句「请你告诉我是哪个角色」
就结束——那等于把活推回去了。实测里「拿不准 → 停下来反问」是最常见的空转。

**「有没有 xxx 的图」**在中文里常是问**有没有现成的**。有图片检索能力
（浏览器 / danbooru）就先当找参考图办：去检索给用户看，顺手可以附一条
照着参考写的新提示词。没有检索能力才按 C 档给新方案，
并用一句话点明这是新写的提示词、不是找已有的图。

## 版权角色先查档案（有检索能力时）

构思涉及版权角色而你对它没把握时，**先查再想**——能联网就广查
（wiki · 萌娘百科 · danbooru 该角色的 tag 页和图），不要止步于 tag 词典：

- **外貌结构**：耳朵/角/尾巴到底是什么。空弦那对像猫耳的是**耳羽**（原型狮鹫，
  种族神民）；铃兰原型是九尾狐——写错结构，会跟角色名自带的设定打架。
- **性格与职能**：吉他手还是主唱、活力位还是吐槽位、剧情里在哪儿干什么
  （空弦本职在修道院）——决定「画她做什么」才像她。
- **皮肤与梗**：联动皮 / 季节皮（铃兰有罗小黑联动春装和冬季和服）、
  社区梗（「铃兰小姐是我们的光」）——都是构思的现成素材。

**档案用来做决定，不直接抄进提示词**：默认外貌交给角色名（写法 §3.7）；
用户明确指定的服装、饰品和外观改动逐项保留，未指定部分才用简洁成套说法。
性格落到动作、表情和关系上；梗化成画面情景。
查不了网的环境，回到写法 §4.2 的保守规则——没把握就不分配职能、不写细节。

**角色收录不确定时先核对名称**，不凭发布日期断言名字一定有效或无效。
**边界期角色（收录不确定）走中间档**：名字照写（拼法无从核实就
「名字 (作品名)」空格加半角括号，**不自造下划线连写**）+ 2–3 个查档得到的
**结构性**外观词兜底 + 输出末尾一行风险提示（可能没收录，外观词是保险）。
发布 / 实装日期可作参考，不能代替收录证据；不把模糊印象当作查证结论。

**引用数顺手看一眼**：danbooru 引用数≈词条强度（对数关系，约 3000 触顶），
但**不是绝对因数**。查档发现引用数明显偏少时不改写法，
**在输出末尾提醒用户**：该角色激活力可能不足——一致性可能差、
多人同框易被高强度角色盖过，必要时加权或单独出。

**查档案 ≠ 必须守设定**。默认贴设定；但**故意 OOC 是完全合法的构思选项**
（反差、AU、换装、玩梗），很多好图就是 OOC 出来的。查档案的意义是让你
**知道自己在偏离什么**——有意识的 OOC 和无知的写错（把耳羽当猫耳）是两回事。
故意改设定落笔时按写法 §3.7 的改动规则：保留逐项要求与指定权重，必要时尝试加权，
并且明说是改动。

## 按动画岗位检查构思

一张图从想法到分镜，可按编剧、监督、原画、摄影检查职责。
这些决定可以往返调整；交付前，空间、人物动作、光色必须彼此成立：

| 岗位 | 做什么 | 落到这张图上 |
|---|---|---|
| **① 编剧** | 先有想法 | 模糊需求 → 一个有记忆点的**概念** |
| **② 监督** | 转成情景和镜头 | 概念 → 相机、景别、视觉中心、前中后景 |
| **③ 原画** | 给内容 | 人物、可冻结的动作、谁对谁做了什么 |
| **④ 摄影** | 上氛围 | 光、色、对比、质感 |

**光色最终必须与空间、人物和机位相容。** 可以先有光色灵感，再找合适的场景、
光源和遮挡关系；发现不相容时回调，不把灵感先后当成错误。

**为什么不能跳过编剧和监督**：直接从词表挑高频词拼起来，出来的是一份道具清单，
不是一场戏。材料要服务同一个画面意图。

### ① 编剧：找那个有记忆点的一下

**核心不是堆元素，是设计一个独特、有记忆点、有视觉叙事的概念。**

具体手法：**先在心里排除掉这个主题最常见的五种普通构图**，再从这几处找新鲜感——

> 相机位置 · 人物距离 · 裁切 · 遮挡 · 透视 · 动作 · 与环境的互动

⚠️ **不要靠花瓣、粒子、星星、光效、大量漂浮物制造虚假的丰富感。**
那是没想清楚时的填充物。

### ② 监督：协调空间与人物

先给相机高度、观看方向、景别、视觉中心和前中后景一个初案，
再与人物动作互相校正。人数或动作变化时允许回调机位，空间方案服务画面意图。

⚠️ 不要默认所有人物同样大小、全部全身出镜、站在同一平面。
近景人物可以只露局部，中景承担主要动作，远处人物应当明显缩小。
可以优先考虑：低机位 · 俯视 · 贴近前景 · 隔着物体观察 · 边缘取景 ·
局部遮挡 · 倒影 · 门窗或镜面框景。
**但所有的尺度和遮挡必须服从同一个明确的相机位置**，不能各自为政。

### ③ 原画：给内容

**每个人物都必须正在进行一个具体、可冻结的动作，并且与环境有互动。**
「三个人在野餐」是三个各自独立的人；「一个人正把西瓜递过去、第二个人手伸到一半、
第三个人在低头看手机」才是一张图。

多人时逐人定：外貌 · 服装 · 位置 · 远近 · 裁切 · 姿势支撑 · 动作方向 ·
道具归属 · 视线 · 表情——判据是**能不能回答「谁对谁做了什么」**。
每个人的施受和参与度（施加 / 承受 / 旁观 / 不在场）都要定；
「完全不在场」也是一种参与度，而且常常最衬戏。

### ④ 摄影：上氛围

主光方向与性质 · 第二光源 · 色温 · 对比 · 材质。
记录光色在本方案里起什么作用，取向说明只点明它与其他方案的区别。

## 交棒给写法层（会议散了，上作画桌）

分镜定了，把它写成提示词是**另一门手艺**，规则在 `通用写法`。
四个岗位在本篇做的决定，各有各的落笔归宿：

| 岗位 | 会议桌上决定了什么（本篇） | 作画桌上怎么落笔（通用写法） |
|---|---|---|
| ① 编剧 | 有记忆点的概念、正在发生的那「一下」 | 化进句子段：进行中的动作、光影叙事（§4） |
| ② 监督 | 空间、相机、景别、视觉中心 | 取景/机位词组（§3.3）、占画幅句（§4.4） |
| ③ 原画 | 谁、什么动作、谁对谁做什么 | 人数与姿势词组（§3.1/§3.4）、角色栏外貌（§0.1）、施受前缀（§4.9） |
| ④ 摄影 | 光、色、对比、质感 | 光影叙事句（§4.6）、氛围色彩与技法块（§1 的后排块） |

跨岗位的通用规矩也都在那边：字段怎么分、顺序怎么排、
哪样内容用词组钉死、哪样用句子讲清。

交棒时对每一样内容只问一个问题：**这一样必须钉死吗？有没有现成的词能钉？**
找到词就钉住——这是把想法落地的第一步；找不到就改用句子，不是放弃，是换笔法。

实际启用的补充写法有明确要求时，由它接管对应部分；没有时完整按通用写法输出。

## C / D 档的三条硬约束

1. **每条方案至少在两个层上不同**（题材 / 动作 / 场景 / 镜头 / 光色 / 氛围）。
   只换发色或只换服装的两条不算两条。**真正的差异要在①那一层**——
   三条方案「有记忆点的那一下」如果是同一种，换再多格子也是同一张图。
2. **至少有一条探索不同于其余方案的方向**，可从光线、版式、视线、主体占幅或留白改变。
   熟悉的表达也可保留作基线；不预设哪一种是用户最不想要的。
3. **每条末尾一行取向说明**，说清这条方案的画面意图及与其他方案的区别。
   这是说明取向，不是复述流程。A 档不写；B 档改成一句「补了哪几处」。

展开时每格挑几个、从哪个池子，见下面「展开的池子与配额」。

## 多条方案的输出格式

每条完整给一遍通用写法 §0 的字段块，前面加一行标题；**不要几条共用一个角色栏**：

```
方案 A · <四五个字的取向，如「黄昏逆光·远景」>
<主串直接写，不带「Prompt:」标头（写法 §0，2026-08-31 起）>
Character 1:
…
UC:
…
一行取向说明

方案 B · <取向>
…
```

## 展开的池子与配额

### 展开检查：从题材到调子

下面六格是默认检查顺序，填表中可返回修改。人物、动作、空间和光色共同成立：

```
① 题材 / 场合   ── 画面意图与内容范围
② 谁            ── 人数、体征。人数一变，构图整个换一套
③ 在干什么      ── 动作 · 互动 · 表情
④ 在哪          ── 场景 · 时段 · 道具
⑤ 怎么取景        ── 取景 · 视角 · 构图 · 主体占幅
⑥ 什么调子      ── 光线 · 色温 · 对比 · 氛围
```

**交付前检查相容性**：光色要有符合场景的来源与遮挡关系。先想到某种光色时，
可以回调人物、机位或场景；六格是检查框架，不是单向锁定的创作过程。
每格先取自任务要求，未指定的内容按画面意图补足。回调后再过下面的清单。

---

### 交付前 review（回调之后必跑一遍）

> **这份构思清单尚无对应的出图验证**，用于检查内部一致性，不承诺生成效果。

六格填完（或回调改过任意一格）之后，交付前逐条对一遍。**任何一条答不上来就回对应的格重填**：

1. **光源在场景里成不成立？** ⑥ 的主光方向与性质，能不能在 ④ 的场景里找到实际来源
   （窗、灯、天空、火）？室内说逆光就要指得出光从哪扇窗进来。答不上来 → 回 ④ 或 ⑥。
2. **机位与人数、动作相容吗？** ⑤ 的取景与视角，容得下 ② 的人数和 ③ 的动作吗？
   特写装不下三个人递西瓜；全身俯视看不清表情。答不上来 → 回 ⑤ 或 ③。
3. **探索方向有没有在取向说明里讲明白？** 明确改变的镜头、动作或光色，应能从说明中看出目的。
4. **角色栏与主提示词的分工对不对？** 体征 / 发型发色 / 服装 / 配饰 → 角色栏；
   动作 / 场景 / 道具 / 光影色彩 / 氛围 → 主提示词。交互句可复用辨认必需的简短外观锚点，
   不复制完整外观清单；用户明确的服装、饰品和外观改动逐项保留。
   表情默认留在主提示词；施受前缀所需的例外按通用写法 §4.9 处理。
5. **参数是否符合实际要求？** 未指定时用通用写法 §7 的功能默认参考；
   已有具体值不静默更换，需要偏离时说明理由。
6. **各条方案真的不一样吗？**（C / D 档才问）「有意思的那一下」是否各不相同，
   而不是同一种换了发色。

---

### 每一格挑几个、从哪个档挑

| 格 | 默认检查量 | 选择依据 |
|---|---|---|
| ① 题材 / 场合 | 一个能说清的画面意图 | 任务给出的范围，或本方案要表达的情境 |
| ② 谁 | 人数明确，角色锚点完整 | 已指定角色不改；未指定时按题材选角 |
| ③ 干什么 | 动作可先按 3–4 个元素组织，表情按复杂度选 1–3 个 | 每个元素承担动作、反应或互动作用；动作参考量可调整，表情在 1–3 个内按复杂度取舍 |
| ④ 在哪 | 场景明确，道具与服装够支撑行动 | 不凑数量，不给既定角色擅加特征 |
| ⑤ 怎么取景 | 取景、视角、构图各有明确选择 | 同一画面内相容，主次可辨 |
| ⑥ 什么调子 | 主光明确，色温、对比和氛围协调 | 先确认光源，再写需要的光效 |

这些是构思参考量，不是图库中位数或效果最优配额。表情词应相容，不把互相冲突的表情凑满。

- **B 档**：补足缺的情景和镜头，让给定主体清楚成立；不另设固定场景。
- **C / D 档**：兼用熟悉与探索性材料。一组方案可保留一条以熟悉表达为主的基线对照，
  其余在动作、场景或镜头层形成明确差异，不机械要求一半主力或同一种配比。

---

### 让几条方案真的不一样

约束是「每条至少两个层上不同」。**层指的是上面 ①–⑥ 这六格**，
换发色、换服装颜色都在同一格里，不算。

**但真正的差异在①那一层**：三条方案如果「有意思的那一下」是同一种
（都是「一个人在看另一个人」），那换再多格子也还是同一张图。
先想三个**不同的有意思**，再各自往下展开。

一个好用的分配法——三条方案分别动不同的格：

| | 动哪两格 | 效果 |
|---|---|---|
| 方案 A | ⑥ 调子 + ⑤ 镜头 | 同一个人同一件事，换一种取景。跨度较小 |
| 方案 B | ③ 动作 + ④ 场景 | 同一个人换一件事做。中等跨度 |
| 方案 C | ① 题材 + 任意一格 | 换一个方向。**这条通常就是走空地的那条** |

---

### 空地那条怎么走

默认先选一个能形成差异的方向。如果两个方向共同服务同一画面意图，可以组合；
说明中点明它们，并检查其他层不冲突。下表是选择入口，不是预设题材：

| 空地 | 具体怎么落到提示词里 |
|---|---|
| **硬光 / 强对比** | `harsh lighting` `high contrast` `cast shadow` + 句子写投影形状 |
| **不直视** | 把 `looking at viewer` 换成 `looking away` / `looking down` / `looking back`（互斥组只挑一个，见通用写法 §3.9） |
| **远景小人** | `wide shot` + 句子写「人只占画幅的一小块，环境是主体」 |
| **黄昏 / 日落** | `sunset` `golden hour` `backlighting` + 暖色温 |
| **负空间构图** | 主体推到一侧 + 大片留白，用句子写，tag 没有好词 |
| **分格** | `multiple views` / `comic` + `inset`；多格写法见通用写法 §4.10 |
| **贴纸 / 设定集** | `sticker` / `reference sheet` + `simple background` |

**这里的“空地”指相对已有方案尚未探索的方向。** 有适用统计时也可指较少见的表达，
不能据此说“没人做”或“一定更好”。取向说明写清改变了什么、服务什么意图。

---

### 取向说明怎么写

**一行，说画面意图与差异，不说流程。** 不依赖外部频次表，也不用统计数字解释自己的选择。

> ✅ 「让光影承担张力，其余元素保持简洁。」
> ✅ 「缩小主体占幅，让环境成为叙事重点。」
> ❌ 「我先确定了题材，然后挑了动作和场景，再补了光线……」（这是流程复述）

**A 档和 B 档不写这一行**（B 档改成一句「补了场景和光线」即可）。

### 一个完整例子（C 档）

用户：「有没有夏天的图」

以下示范无图片检索能力时如何展开，具体场景只用于演示，不是后续任务的默认。
先点明这是新写的提示词，再给方案：

| 格 | 方案 A（黄昏逆光） | 方案 B（室内午后） | 方案 C（远景 · 空地） |
|---|---|---|---|
| ① 题材 | 放学路上 | 房间里避暑 | 无人的海边 |
| ② 谁 | 1 人 · 猫耳 | 1 人 · 猫耳 | 1 人 · 猫耳 |
| ③ 干什么 | 走着 · 回头 | 趴着 · 困倦 | 站着 · 远眺 |
| ④ 在哪 | 河堤 · 夏日 | 室内 · 电扇 | 海岸线 · 正午 |
| ⑤ 怎么取景 | cowboy shot · 平视 | close-up · 俯视 | **wide shot · 远景小人** |
| ⑥ 什么调子 | 逆光 · 暖 · 中对比 | 柔光 · 暖 · 低对比 | **硬光 · 冷暖对撞 · 强对比** |

A 与 B 的动作、场景、镜头和调子不同；C 改变题材、镜头和调子，组合远景小人与硬光。
这两个方向共同服务该例的空间与日照意图，不因“常共现”才允许，也不是唯一可用组合。

取向说明分别是：
> A：「让光线与回望动作形成同一个瞬间。」
> B：「保留一条熟悉表达的基线对照。」
> C：「缩小主体占幅，并用硬光强对比突出环境。」
