# 通用构思

<a id="method-ideation-ideas"></a>

<a id="ideation-ideas"></a>

## 整体想法构思

先想值得展开的内容：想表达什么、谁处于什么处境、什么关系或变化让人记住。想法可以从人物、情绪、世界规则、矛盾、声音、物件、梦境或形式实验出发，不必一开始就适合某张画、某种模型或现成词库。

用户要一个点子就给一个扎实点子，要比较方向才展开所需选择。整体构思可以停在主题、故事种子、角色关系或梗概；不默认附镜头表、提示词或下一阶段确认表。

普通构思从本次题材、已提供资料与已启用的整理后偏好发展，不自主检索历史作品、旧提示词、反推或维护记录来找现成方案。用户明确要核对依据、分析指定作品或制作其变体时，再读取相关材料。常用题材、媒介与形式可以复用；独立新方案重新决定动作、物件作用和空间安排，不能只换旧例子里的名字。用户要求延续系列时保留指定的共同部分。

<a id="ideation-ideas.scope"></a>

### 从还没决定的地方开始

已有主题就沿它发展，已有故事就只处理未定关系或走向，明确只想找现成图片则如实按检索任务处理；没有检索能力时说明，不能把新构思冒充找到的图片。已给出完整画面而只要转词时交给 `nai5-writing`，不重新创作。想法已成立而要变成单幅构图，可接 `nai5-illustration-composition`；要安排漫画可接 `nai5-comic-storyboard`，这些都不是必须依次经过的步骤。

资料不足时，先用已知内容提出具体主案，新增设定标为建议。只有缺口会影响当前任务或用户锁定事实时才问，例如不知道要延续哪个结局；角色身份未确认的部分保持开放。

用户明确的角色、剧情、服饰、镜头、文字与改动范围先保留；原句、空格、标点和其他冻结文字不因润色而改。未指定部分可以充分发挥，幻想、荒诞、静观、留白或非叙事表达都可以成立。只改一个想法的落点时保留其余已认可内容。

<a id="ideation-ideas.explore"></a>

### 找到有记忆点的核心

可以顺着当前兴趣试探这些方向，而不是逐项填表：

- **关系和反差**：谁依赖谁、误会了什么、习惯在什么场合失效？熟悉的人或物进入不相称的环境会发生什么？
- **欲望和代价**：想得到什么、为什么不直接拿到、做出的选择透露什么？抒情或日常小品不必硬加危机。
- **规则和例外**：把世界里的一个常识改变后，生活会怎样？保留可理解的后果，让奇想有自己的逻辑。
- **感官和情绪**：从温度、声音、材质、空旷、压迫或亲近感出发，找能承载它的情境，而不是先罗列装饰。
- **物件和母题**：一件物如何改变关系，重复出现时意义怎样变化？物件也可以只是审美重点，无需都变成机关。
- **形式和视角**：把一个事件交给不常见的观察者，用书信、物件痕迹、相册、梦或并列日常来组织。书信可以只让人知道写信者愿意透露的部分，相册可以用相邻照片中的变化呈现时间；按想让人先知道什么、暂时看不到什么来选。

**用户没给内容、或只给了角色没说画什么时**，按画师没题目时的想法来。先抓一个具体的小东西起头：一件东西、一个动作、一句话或一个词，不先定地方和气氛。再对它做一次变化，让它变成一个点子：和另一样东西合在一起，放进它不该在的地方，变大、变小或换材质，换一种用途，想它的反面，想它之前或之后，把预期反过来，模仿一个大家认得的东西，或者拿它的字面意思开个玩笑。然后由这个点子长出画面：谁在场、在哪、什么时刻、什么光都为它服务，气氛最后定；没给人物时，这个人是谁、长什么样，也从点子里来。一路往前做，想到一个能画的点子就用它，不在几个点子之间来回比，推敲只用来把这一张做好。只交一个方案，交稿时先用一句话说这张画的是什么；同一会话里再要一张时，换一样起头的东西和一种变化。

熟悉的表达与未尝试的方向都可使用，不预先排除常见构图。补充花瓣、星星、粒子或漂浮物时，说明它们带来的可见变化：例如花瓣被风带向人物伸出的手，或零散亮点使一片暗处显出深度；只需要装饰时，也可用它们安排边缘和疏密。

<a id="ideation-ideas.character"></a>

### 角色事实与创作自由

版权角色不熟悉且确有查询能力时，核对相关档案和可靠参考：外貌结构、性格与职能、故事背景、已有服装和文化语境。资料是帮助理解角色的材料，不是把所有已知信息都塞进方案的要求。查询不到时保留用户事实，不把模糊记忆写成已核实设定；不确定内容可以作为有意的创作建议。

查档案不等于只能照原设定。反差、AU、换装、玩梗和有意 OOC 都可以是明确的创作选择；要知道自己偏离了什么，区分有意改变与无意认错。角色是否被模型收录、规范标签拼法和激活强度属于写法问题，不限制想象。

使用已有原创角色时，以用户提供或实际启用的资料为事实，在本次开放范围内发挥，不臆造私有条目。用户明确要求从零设计 OC 时，可以大胆提出身份、性格、外貌和关系方案，并将新增内容作为本次设计提案；没有 OC 库不妨碍创作。角色名字、既有形象和本次可以改变的部分分清，一次提案不自动写回永久设定。

<a id="ideation-ideas.topics"></a>

### 按本次题材选读

需要深入某个方面时再选相应专题：完整稿按下列同名专题章节选读，独立包则按已启用的技能接续。未启用其他技能时，用当前包的方法完成能做的请求，如实说明边界，不声称读过缺失资源。专题可以组合，也可以停在当前想法，不是必须全部经过的分类流程。

- 场景与情境（可选技能 `nai5-scene-design`）：让环境成为主体，发展空间的生活、运行、时间与气氛。
- 情绪、象征与艺术表达（可选技能 `nai5-art-direction`）：探索感受怎样通过画面关系、象征、节奏和形式成立，也可按需分析参考风格。
- OC 整体角色设计（可选技能 `oc-character-design`）：从零发展角色核心、世界关系、行为与外形，或修改已有角色的开放部分。

漫画架构、页格与分镜沿用 `nai5-comic-storyboard`；具体服装设计沿用 `oc-costume-design`。例如环境主导的漫画可以在需要建立场景时读场景专题，已有 OC 的换装则直接处理服装，不重新设计人物。用户给定的具体细节与冻结原文随当前方案保留，未选专题不默认加载。

成人向是可能与各题材交叉的内容范围，不等于一种画风或媒介；非露骨与露骨范围按当前明确要求区分。本导航仅作中性分类说明，不提供露骨内容的创作方法、示例或生成技巧。

<a id="ideation-ideas.compare"></a>

### 让不同方向有真实区别

比较方案时看体验或核心关系是否变化：同一事件换成另一人的视角、从冲突转为日常观察、让环境而非人物主导、把直接揭晓改成余韵，都会带来有意义的变化。用户要配色变体时，只变颜色也可以是完整目标，不强制每案改变多个维度。

需要解释时简短说出方案的吸引力、保留的用户要求和仍开放的部分。不要复述内部流程，也不预设必须给出基线、探索案或取向说明的数量。首答交实际想法，不只列接下来准备想什么。

<a id="ideation-ideas.handoff"></a>

### 交付与接续

交出本次需要的主题、梗概或故事种子；可以指出一个值得继续展开的问题，不强迫把它全部解决。接下一阶段时带着现有文字与用户已经确定的内容即可，不要求重新填写一份交接模板。构思到此可以独立完成。

## 场景与情境构思

从一个地方怎样存在、怎样被使用，以及它让人产生什么感受出发。场景可以是故事发生的条件，也可以独立成为观看主体：空旷的盐田、正在苏醒的车站、始终无人经过的连廊，都值得作为完整作品。用户已经给出的地点、时代、天气、物件、人物与可见细节先保留，从尚未决定的环境关系展开。

只要场景点子就交具体情境；要环境设计才深入空间、运行与材料；已有场景要构图则围绕当下观看关系落实。以下方法按问题选用，例子是原创假设，不是用户设定或固定素材池。

<a id="ideation-scene.subject"></a>

### 让环境承担画面的吸引力

先抓住这个地方最值得看的一种关系：庞大的结构与细小的使用痕迹、平稳秩序中的局部变化、明亮表面下的幽暗通道、看似相同却逐渐偏离的重复。要看巨大结构，就留出从近处基座到远处顶端的轮廓，人物可小到只作尺度参照；要看使用痕迹，就靠近扶手、门槛或台面，让磨损位置可辨。人物需要交代使用方式时再入画，例如弯腰穿过矮门。

环境成为主体不等于只能画大远景。反复修补的门槛、夜里仍温热的石墙或柜台上被磨亮的边缘，都可以借局部让人想见整个地方。远景适合展现地形和结构的呼应，局部适合触觉与时间，中间尺度能看清怎样进入、停留和使用。

例如，构思“退潮后短暂开放的市场”，吸引力可以是摊位沿露出的石脊铺开，水沟保留刚才海面的亮光，较高的平台已经开始收摊。这里的地点、时间和使用方式相互解释；不必再塞入一个戏剧人物，环境本身已有变化。

<a id="ideation-scene.life"></a>

### 从生活与运行方式长出空间

想象这里平常如何运转：人或其他使用者从哪里进入，东西如何运送，何处工作、休息、交换、储存，什么需要照料，哪里会被反复触碰。挑与当前场景有关的过程，把它变成路径、开口、设施和摆放关系。物件由用途找到位置，空间就不只是装饰的集合。

同样一间修理铺，面向街坊的日常服务可能让门口宽敞、常用工具伸手可及，等候处能看见工作；专为高塔维护的工坊则可能围绕升降与悬挂组织。前者可把工具架放在工作台后、等候凳放在门边，留出顾客与工作区之间的通道；后者可让工作平台围绕竖井分层，吊索穿过各层。新建、洁净、被精心维护的地方也有生活痕迹，不必靠破败和杂乱证明真实。

幻想场景可以从自定规则推演：若物件会向光缓慢漂移，储存、遮阳和交通会怎样适应？可以把储物架移到背光墙、给开口加遮光帘，或让收货处朝向光源，物件自己缓慢靠近；选择与当前画面有关的后果展开。非叙事或纯形式的环境也可依靠重复、重力方向、材料变化等视觉关系成立，无需补全社会制度。

<a id="ideation-scene.space"></a>

### 建立可感知的空间关系

用边界、通路、层次与遮挡让地方有结构。入口通往什么，何处收窄或展开，视线在哪里被截住又重新打开，附近与远处怎样呼应？需要让人理解路线时，让入口、转角和远处目的地至少有可辨的连接，例如地面亮带转过柱脚后通向楼梯；需要迷失感时，可让相似门洞重复到远处，并用近墙遮住岔路的一端。

尺度靠关系显现：扶手与手、楼梯与步幅、树根与建筑、风化纹理与远方轮廓。可以保留现实尺度，也可以有意拉长、压扁或错置；判断依据是本题的表现逻辑。用户明确要看见的细节应进入方案，必要时调整观看位置与主次，而不是先把它们当成可删的杂物。

场景还包含画外：通道继续到哪里，声音从什么方向来，窗外的光意味着什么。画外空间能扩大想象，不需要把每个去处都解释或画出来。局部修改一座桥或一个入口时，检查相连路径与使用关系即可，保留其他已经成立的空间。

<a id="ideation-scene.time"></a>

### 用时间与天气改变同一个地方

选择正在发生的时段和变化，而不只贴“清晨”“下雨”的标签。早班开始前，哪些地方先亮起来、哪些仍关闭？雨刚停时，什么先干、什么还积水？风会带动柔软物、暴露朝向差异，也可能让原本热闹的路径暂时空下来。

痕迹应来自原因：搬运留下的磨损落在常走的边缘，褪色跟随受光面，反复开合改变接触处，临时搭建留下与长期结构不同的连接。洁净与未被使用也能表达刚刚建成、被保护或等待启用。选择能形成当前感受的痕迹，无需为所有表面编年史。

叙事情境可让痕迹提示刚发生的事或将发生的变化；静观环境则可以停在循环本身，如光斑缓慢移过空座椅。并非每一处痕迹都要成为谜题、危险或待回收的伏笔。

<a id="ideation-scene.material"></a>

### 让尺度、材质和气氛相互作用

材质不只是物品名称：厚石墙的窄缝可以只照亮内侧一道边，湿木板把灯光拉成长反光、旁边干布仍保持柔暗，薄金属片则用翘起的边缘和松动挂点显出轻薄。把表面、厚薄、边缘、透光和使用状态连到空间体验，选择与本题有关的表现。

气氛可来自彼此配合或抵触的关系。温暖小灯被巨大冷空间包围时，灯下放近座椅、杯子和可进入的小门，可以使亮处像可停留的住处；把灯留在远处高窗、前面隔着无路穿过的空场，会增加距离感。同一冷暖配色，通过入口、生活物件和距离就能形成不同情境。

色彩可以服从自然光，也可以组织平面色块、季节感或象征。明亮、整齐、普通的环境同样能有个性；幻想材料和异常尺度可以大胆使用，只需让它们在当前作品中有可感受的联系。

<a id="ideation-scene.deliver"></a>

### 交出本次需要的地方

把场景写成能被想见的方案：它是什么样的地方，最有吸引力的关系是什么，空间或生活如何支撑这种关系，以及本次时刻有什么值得看。只要一个氛围点子时可以很短；环境设计需要时再展开区域、运行、材料与变化，已有答案不重复填表。

环境要进入插画时，可接 `nai5-illustration-composition` 选择具体观看方式；要在漫画中反复出现，可接 `nai5-comic-storyboard` 安排地标、揭示与连续性。用户直接给出完整画面并要转词时，带现稿交 `nai5-writing`。场景方案本身也是完整结果，接续只发生在当前请求需要的地方。

## 情绪、象征与艺术表达

具象、写实与风格化画面都适用这里的情绪、象征、构图光色及媒介画风探索；抽象与超现实只是可选方式，不默认把用户的具体场景抽象化。

从想让观者感受到什么、怎样观看和联想出发，探索画面的形式；画风与媒介选择服务这种体验，也可以成为探索的起点。用户已经确定的主题、人物、服装、物件、文字和镜头继续保留，在开放部分发展表达。下文的例子是原创假设，用于说明选择怎样产生不同感受。

只要表达方向就交有画面内容的提案；需要风格分析才展开参考的视觉做法；已有方案只调一处形式关系时，保留其他已认可决定。构思阶段谈感受、形状、笔触和观看体验，不把它们提前变成标签配方。

<a id="ideation-art.feeling"></a>

### 把感受发展成观看关系

情绪可以有方向、强弱和转折：是想靠近却有所保留，已经结束却还不愿离开，还是安静地被某种庞大事物包围？可以用接近的身体与回避的视线表现保留，用已收起的物件与仍停在门口的人表现不愿离开；表情再配合这些位置和动作。

距离、遮挡、触碰、视线、物件位置与空缺都能承担感受。例如“仍为离开的人留着位置”，可以让餐桌其他位置都被日常杂物占据，唯独那一处整洁；也可以只画对面椅背上的余光，让缺席没有明确解释。前者更易读出日常关系，后者更含蓄，选择取决于希望观者停留在哪里。

也可以从愉悦、丰盛、平稳或纯感官兴趣开始，不必先制造痛苦和矛盾。色彩间轻快的呼应、缓慢展开的形状或触感相近的表面，都能支撑没有故事结局的作品。

<a id="ideation-art.metaphor"></a>

### 让象征在画面里发生关系

先理解本题中一个物件或形象为什么承载意义：它和人物的经历、动作、场所或反复出现的方式有什么联系？然后决定通过尺度、位置、变化、缺失或组合，让这种意义可被感受到。象征不等于给抽象概念配一个通用图标；同一物件在不同关系中可以产生相反含义。

例如“无法寄出的道歉”可以让信封越来越厚，桌面逐渐没有可写的位置；也可以让一张薄纸占据很大的空白，字迹只停在开头。前一种让信封挤占桌面、压住未写完的纸，后一种让短短开头落在大片空纸上；观者分别看到积累的负担与停笔后的空缺。用户已经指定某种象征物时，优先把它组织好，而非换成更常见的符号。

隐喻可以容易读懂，也可以保留歧义。要让观者理解因果，就建立必要的前后或接触关系；要留下余味，就让意义有可探索的线索，不把画面说明写成唯一标准答案。采用有文化背景的符号时，区分已知含义、参考给出的依据和自己本次赋予的意义。

<a id="ideation-art.rhythm"></a>

### 用节奏、密度和留白安排体验

关注眼睛怎样进入、停留、离开或回看：密集区域会怎样衬出空处，重复形状在哪里发生变化，硬边在哪里变软，色块之间有没有呼应。节奏不只来自斜线和动作，等距排列、微小差异和长时间的静止也能建立观看秩序。

留白可以形成等待、距离、轻盈或压迫，取决于它和主体的关系。一个物件靠近边缘时，空处可能像未到达的地方；被密集纹理围住的小空处则可能像呼吸。要表现尚未到达的距离，可把主体放在一端，在它面向的方向留出连续空处；要使小空处像喘息的位置，可让周围纹理密集、靠近空处时逐渐稀疏。面积随这段距离或密度变化调整。

若要加强表达，先改变最相关的关系。例如把重复的间距逐渐拉开，可能比再添加一个象征物更清楚。用户指定必须出现的细节，通过层级、疏密和位置协调；它们不因“做减法”自动失去保留资格。

<a id="ideation-art.unreal"></a>

### 抽象与超现实各自怎样成立

抽象可以从真实经验中提取关系：水面波动留下的节奏、拥挤与疏散的密度、记忆由清楚变模糊的边缘。选择想保留的运动、形状或色彩联系，让它们成为画面内容；不必最后又加一个写实人物来解释主题。

超现实可以改变尺度、材料、空间或时间之间的关系。先选择本题有意味的变化，再想其可见后果：若一间屋子随着记忆被折叠，可以让墙角形成折线，桌面与门框沿同一折线弯转，窗光也在折面上转向。变化可以局部而含蓄，也可以使整个世界遵循另一种逻辑。保留足够的感知线索，让观者知道异常发生在哪里，而不要求幻想符合现实工程。

梦境、拼贴和象征层可以并置不同时间或视点。决定哪些部分属于同一现实、哪些是联想或叠置，表达才有自己的方向；不必为了消除所有矛盾而把它们整理回普通场景。用户要的荒诞本身也可以成为目标。

<a id="ideation-art.form"></a>

### 选择媒介、形状与笔触的作用

先问需要怎样的表面和边缘，再选择表达语言。连续细线可以追踪犹疑的动作；大片平涂可让深色块贴近浅色人物轮廓，压缩它周围的空处；柔软渗化可以让边界消退；粗粝痕迹可以保留摩擦与速度。这些是可尝试的作用关系，不是某种媒介必然对应某种情绪。

形状也有自己的组织：圆润与尖锐如何相邻，完整轮廓在哪里断开，人物与背景采用同一种形状语言还是刻意分离？材质与笔触可以统一全画面，也可以只在关键区域变化，让观者从流畅处停在异常处。已锁定的外形与服饰结构仍应能辨认，风格化的幅度按用户要求掌握。

选择水彩感、版画感、拼贴、素描或数字绘画等方向时，具体说明需要的是透叠、压印边缘、纸片搭接、线条密度还是其他可见做法。这样即使媒介名称相同，方案也有区别；即使不用媒介名称，表达意图仍然清楚。

<a id="ideation-art.reference"></a>

### 从参考中分清题材与表达

有参考图时，先描述真正看见的组织方式：主要明暗块各占哪里，冷暖色相邻还是隔开，轮廓何处清楚何处消失，笔触相对人物有多大，远近景是否压在同一平面，以及细节集中在哪些部位。再判断哪些做法可能促成当前感受，区分可见观察与个人解释。没有实际读到的参考，不声称已分析其风格。

此处分析用户实际提供或指定的参考。普通创作不因追求某种个人取向就自行搜索其旧作品或反推；已有整理后偏好可直接使用。核对偏好依据与整理参考另按用户明确要求进行。

对照参考时，分清用户要借用的是光色与媒介、常用形式，还是这张图的具体构图。即使更换角色与道具，保留同一组姿势、空间分层和物件作用，也可能仍是原图变体。独立新图从当前内容重新组织这些关系；用户明确要沿用指定构图时保留其指定部分。

组合参考时让各自有作用：一个帮助理解光色，另一个帮助研究线条或空间，最后检查它们在本题中能否共存。需要时说明来自哪张已提供参考，避免把自己的新增判断说成原作者意图。具体模型是否识别风格名、如何写画师串，留给写法阶段处理。

<a id="ideation-art.deliver"></a>

### 交付能够被想见的表达方案

交出实际画面关系与感受之间的联系：什么内容承担表达，准备怎样组织形状、空间、色彩、密度或笔触，观者会先注意什么、随后可能联想到什么。只要一个方向就认真发展它；用户要比较时，让方案改变可见安排，例如一案让两人靠近却看向不同方向，另一案把两人隔远但让视线相遇；简短说明各自形成的感受。

给出方案不等于解释尽所有意义。用户只要画面时让画面成立，需要说明时再简短解释选择。已经确定观看方式并要转词，可接 `nai5-writing`；尚要落实镜头与空间，可接 `nai5-illustration-composition`；需要连续叙事则接 `nai5-comic-storyboard`。这些是按任务发生的接续，艺术表达也可以独立完成。


<a id="method-ideation-character"></a>

<a id="ideation-character"></a>

## OC 整体角色设计

围绕一个人或非人角色为什么值得被记住，发展其内在取向、世界关系和可见形象。用户明确要求从零设计时，可以大胆创造身份、经历、性格、外貌与关系，并把这些作为本次方案提出；使用已有 OC 时，则以用户提供或实际启用的设定为事实，只发展本次开放的部分。没有角色库不妨碍从零创作，也不代表可以替已有角色补造历史。

角色核心、视觉设计、关系设定或局部重设计都能独立成为本次终点。按用户需要的具体度展开，不要求先写完整传记；以下例子均为原创假设，不是用户角色档案。

<a id="ideation-character.core"></a>

### 找到能不断生出选择的角色核心

从角色在意什么、怎样看待自己、习惯怎样解决问题入手。一个好用的核心不仅是“温柔”“叛逆”等评价，而能帮助想象他在不同处境中的选择：会保护什么，愿意花时间做什么，在什么事情上退让，又有什么被忽略的需要。

矛盾可以让角色有层次，但不必为每个人安排创伤和秘密。比如一个喜欢为陌生人指路、自己却总推迟出发的巡灯员，既能形成生活习惯，也留下了关系与行动的空间；另一位角色也可以毫无纠葛地热爱修复旧物，吸引力来自专注、耐心与独特的观看方式。

若用户从一个外形点子开始，可以反过来探索它适合怎样的性格与生活；若只要外形设计，就把内在理解用作取舍依据，不额外展开长篇背景。保留用户锁定的核心，变化发生在仍开放的解释和表现上。

<a id="ideation-character.world"></a>

### 让角色与世界彼此影响

想象这个角色在何处生活、靠什么维持日常、与谁交换帮助、受到什么期待，以及他对这些安排有什么态度。职业或种族可以提供起点，真正让角色具体的是他怎样参与其中：同是守门人，有人把门口变成邻里交谈处，有人把每次通行都当作需要认真记录的相遇。

环境与能力会改变习惯和物件。生活在频繁搬迁的地方，角色可能擅长快速整理，也可能坚持带着难以携带的纪念品；需要在狭窄处作业时，可以让常用工具沿腰侧贴身收纳，转身时不向外伸出；若角色偏爱携带大工具，也可让它成为必须侧身通过的动作特点。幻想世界的规则可以大胆设定，再观察它给日常带来什么后果。

关系不只是名单。某个同伴让角色放松，某个职责让他显得拘谨，某段长期合作改变了他们分工的方式；选择与本次设计有关的关系，写出它怎样影响行为或形象。世界足以支撑当前角色即可，不用先填完族谱、组织史或完整地理。

<a id="ideation-character.behavior"></a>

### 把性格变成可观察的行为

把抽象性格放进小处境里试想：收到意外礼物时如何接过，陌生人需要帮助时先看哪里，计划被打乱时怎样处理手边东西？姿态、说话节奏、视线、与他人的距离、对物件的照料，都能让性格被看见。

同一种性格可以有不同表现。谨慎的人可能把常用物品放得很整齐，也可能依靠熟悉的小动作确认安全；温柔不必总是微笑，强势也不必一直张扬。选择与角色生活和当次关系相符的行为，不把外貌特征或身体差异直接当成道德、能力与性格结论。

观察角色在不同关系中怎样变化，能避免只剩一个标签。习惯性的动作可成为辨识线索，但在有理由的时刻可以改变；这个变化本身就能表达成长、疲惫或亲近。用户只要静态立绘时，可从中选适合本次展示的姿态，不强制设计一段故事。

<a id="ideation-character.identity"></a>

### 建立外形辨识与整体轮廓

从身体比例、轮廓、发型或非人结构、面部特征、色块与姿态之间的关系选择辨识方式。远看时依靠整体形，靠近后才看见材质和细节；如果去掉装饰仍有明确印象，后续换装会更有余地。细节型角色也可以成立，只需让观看有主次，而不是处处同样用力。

例如，设计一位在高处工作、随身携带折叠器具的角色，可以让紧凑的身体姿态与向外展开的工具形成对照；也可以选择舒展的长线条和贴身收纳，呈现熟练而轻松的印象。它们表达的是不同选择，不意味着同一种职业只能对应一种体型、姿态或服装。

用户指定的疤痕、左右不对称、配色、物种部位或标志物，都是明确设计条件。通过轮廓、位置、材质和层级把它们组织起来；开放设计中的新特征则看是否帮助形成当前印象，不为“独特”凑异色、伤痕或配件数量。

<a id="ideation-character.system"></a>

### 让造型成为可变化的系统

分清哪些是人物本体与长期辨识，哪些是一次着装、工作装备或当前状态。身体与头发的形态、习惯姿势、常用色彩或物件可以形成延续性；雨天外层、庆典服装、临时受损和某次妆容则可能只是当次变化。具体归属由用户设定与本次方案决定，不把新提案自动写进永久资料。

让形状、色彩与材质有关系，但不要求每处重复同一个图案。例如宽圆的头肩轮廓可以由短宽鞋头轻轻呼应；头部结构本身复杂时，衣服可采用连贯大色块，给耳、角或发型留下可辨的外轮廓。耳、角、翼、尾等部位与衣物、动作共同考虑，是否需要特别结构取决于设计目标，不因出现非人部位就先套固定服装模板。

检验延续性时，想象换一个表情、姿态或场合，哪些特征仍能使其被辨认；变化是否来自本题明确的设计意图。用户要彻底重设计时可以改变核心形象，要配色变体或只改发型时就停在相应范围，不设置每次必须改变的项目数。

<a id="ideation-character.costume"></a>

### 整体角色与服装子任务的分工

整体设计决定这个角色的核心、与世界的关系、身体与视觉辨识，以及衣服需要表达什么。领型、袖型、层叠、单品搭配、材质工艺和衣橱变体，需要深入时接 `oc-costume-design`；带着已有角色事实、场合与开放的设计目标即可。

只有换装任务时，角色本身直接沿用，不先重做人格和世界设定。只有整体角色概念时，可以说明服装的大方向而不展开每处扣件；用户同时要求完整外形与衣服时，两者要形成可用的整体方案，不能以职责划分截断本次要求。设计中的可选提案与用户已经确定的内容分清，已有明确决定继续使用。

<a id="ideation-character.evaluate"></a>

### 用具体处境回看设计

在本次需要的范围内，想象角色如何站立、使用关键物件、与他人相处或换一个场合。这样能看出轮廓是否妨碍当前动作、道具是否只是无来由的装饰、性格与外在表现是否有足够联系。纯象征、幻想或舞台造型可以按其表现逻辑成立，不需要全部合理化为现实日常。

若某部分不成立，先定位是核心印象、行为关系还是外形组织需要调整，再修改相关部分。用户已认可的特征保留，通过其他开放关系寻找解法；需要动到锁定内容时指出具体取舍，而不是默默把角色改成另一个人。

<a id="ideation-character.deliver"></a>

### 交出本次可使用的角色方案

从最有吸引力的核心讲起，给出足以理解其行为和外形的具体内容。需要完整设计时，把世界关系、性格表现、辨识特征和造型联系写清；只要概念、外形或局改时按该终点交付。名字、传记、关系网与展示视图按请求需要提供，不为完成表格虚构用户未要求的档案。

角色要进入画面时，可接 `nai5-illustration-composition`；要成为连续故事中的人物，可接 `nai5-comic-storyboard`。用户要把已定外形或衣装转成词句时接 `nai5-writing`，以实际设计事实表达，不假定新 OC 名称已被模型认识。未要求后续阶段时，角色方案本身就是完成的交付。


<a id="method-ideation-composition"></a>

<a id="ideation-composition"></a>

## 想法转插画构图

把已有想法变成一幅具体画面：选择怎样看、看见什么、各部分怎样一起表达。用户已定的主题、角色、服饰、文字、镜头或部件先保留；未定部分围绕画面意图发挥。先让方案说清画面里最值得看的内容在哪里，其他部分怎样围绕它摆放。

用户若只要改视角、人物距离或一个动作，直接处理该处及必要的空间关系，不从头改主题。整体想法尚未定时可以先给本次所需的构图主案；明确要探索主题则交 `nai5-ideas`。形成画面方案就是本阶段的完整结果，不默认继续转词。

<a id="ideation-composition.view"></a>

### 镜头、空间与主次

先问第一眼应看见什么，余下内容怎样引导或衬托它。景别、相机高度、观看方向、裁切、遮挡、透视、主体占幅和前中后景可以一起调整；不是每次都要用同一种戏剧机位。

要强调高度，可把机位放低，让近处结构从画边向上延伸；要看桌面分工，可从斜上方同时看清物件与各人的手；要从隐蔽处观察，可让门边或近处物件遮住部分视野，人物留在后方开口里。近景可只露局部，中景承担主动作，远处人物可以缩小；等大、同平面、正面全身也可以是用户要的展示形式，不能当作必须纠正的错误。

写实空间中的尺度、接触和遮挡应能彼此解释；梦境、拼贴、象征或故意扭曲透视则按其表现逻辑组织，不用现实几何否决创意。用户要求某细节可见时将它作为取景条件，镜头确实装不下就指出具体冲突，不能静默裁掉。

<a id="ideation-composition.action"></a>

### 选择瞬间与人物关系

根据意图决定正在发生什么，或为什么值得停留。递物停在手刚伸到的瞬间、想接又收回的手、另一个人故意看向别处，都比泛泛的“互动”具体。安静站立、睡着、空镜或纯展示同样成立，不强制每个人都在运动或与环境互动。

多人时可考虑谁发起、谁接受、谁旁观、谁根本不参与；这些是创作选择，不是人人必须填满的角色格子。一个人置身事外有时更衬出其他人的关系。动作包含接触或共用道具时，从当前动作确定谁握哪一部分、另一只手在哪里、物件由谁承托、身体靠什么支撑；局部镜头仍说明各只手从哪侧进入。

表情、视线、身体张力和道具状态相互支持。需要一个冻结瞬间时，不把拿起、转身、跑走全塞进同一身体；需要多时刻拼贴时把表现意图说明白。没有“必须几个动作、几个表情”的配额。

<a id="ideation-composition.light"></a>

### 光色、材质与气氛

可以从光色灵感先开始，再寻找能承载它的人物和空间。主光方向与性质、反射或第二光源、冷暖、明暗对比、材质和边缘，共同决定画面情绪；不需要把这些全写成参数表。

写实逆光先交代光源相对人物的位置，再确定哪些边缘受光、正面有没有补光及补光来自哪里；没有补光的暗面保留其明暗区别。用影子提示画外对象时，明确影子进入画面的方向和承接面；环境为重点时，给空间延伸留出面积。舞台光、梦境色或平面色块按各自形式安排，不必模拟同一种自然光。

<a id="general-ideation.s07.h01"></a>

### 按需要回看画面关系

从意图与场合、人物、动作、场景、取景和光色中，选择本次尚未清楚的部分继续展开。人数或站位变化时检查受影响的空间与动作；已有关系成立就保留，不因回看而重做全部构图。

交付前看应当可见的信息是否进了镜头、动作和视线是否表达意图、光色与空间是否符合选定表现逻辑。它们是可往返的观察角度，详略由当前问题决定。

<a id="ideation-composition.variants"></a>

### 变化来自表达，而非凑元素

想比较构图时，可改变观看距离、遮挡、人物与环境的主次、动作瞬间、场合或调子。贴纸、设定展示、留白、分格和画中实物也都是构图方向，只有任务需要才选。方案的数量和变化幅度由当前目标决定。

比较方案时说明改变了哪种观看体验：靠近后能看清哪些反应，拉远后哪些环境关系成为重点，换一个瞬间会让动作表达什么。场所、姿势与光色从当前主题发展，不从教学例子中整套取用；用户明确要沿用某一构图时，保留其指定部分。

<a id="ideation-composition.series"></a>

### 分格展示中的视觉联系

表情集合、衣装展示或设定页不必都变成故事漫画。展示衣装时，可放一张较大的全身图交代轮廓，旁边小图分别放背面开合、袖口或鞋型；表情集合可保持同一脸部尺度，方便直接比较。共同色条、对齐边缘或重复的底色能把视图连在一起，也可以仅靠大小和间距分组。

把版式做成画中实物也是一种选择：侦探线索板、相册页、摊开的拍立得，让多个小画面有共同载体；同样可以用纯平面排版。若有标题，先留出文字区；字在人物后方时说明被哪些轮廓挡住，字在前方时避开需要读清的脸、手和细节。若要连贯叙事，接 `nai5-comic-storyboard` 安排时间与阅读顺序，不把静态多视图自动解释为多个时刻。

<a id="ideation-composition.deliver"></a>

### 交付画面方案

用自然语言交代最值得保留的瞬间、构图、人物与空间关系、必要光色和细节；详略随请求，不必须填完长表。不补提示词字段、不挑标签或处理排除词。用户要继续转成 NAI 提示词时，带现有方案与锁定内容交给 `nai5-writing`；已有方案直接接，不再询问一遍已确认事项。

<a id="ideation-comic-story"></a>

## 漫画架构与分镜

从用户当前阶段开始：只有种子就发展故事，需要架构就安排章节、事件与揭示，已有剧本就拆页格，已有分镜就只做本次修改。四格属于漫画，默认 2×2、从左往右读（左上 → 右上 → 左下 → 右下），竖排等版式只在用户指定时用；不采用固定笑话结构。用户已定的剧情、镜头、服装、原文与读序保留；空白部分允许原创，不以模型标签或提示词长度限制故事构思。

完整新漫画、续写新页或未审阅的新剧情，按末尾完整文字分镜交付并接反馈；纯架构、点子或局改各到本次终点。已定稿转换不是本技能重走创作的理由，交 `nai5-writing` 与 `nai5-comic-writing` 直接处理。

<a id="comic-director.preamble"></a>

### 漫画导演

本方法来自归档材料对视频、教程与用户出图反馈的整理，证据范围见 [研究来源与证据边界](#comic-sources.preamble)。固定事实与逐格状态见 [连续性：固定事实、当前状态与可见范围](#comic-continuity.preamble)。

<a id="comic-director.s01"></a>
<a id="comic-entry.s05"></a>

#### 先固定故事任务

只要点子或梗概时按指定条数和详略交付；完整分镜才使用文末三部分。先标出用户锁定的剧情、镜头、页格数、服饰、台词与原串，导演调整只在未锁定部分进行。

用户只给人物和题材而要完整漫画或分镜时，先创作简短剧本，再拆页、拆格，不索要现成剧本。只要故事架构时交到事件、段落与揭示安排，不强制拆成逐格稿。已有剧本则保留核心事件、动机和指定台词，补足必要承接。参考文档里的“不得添加剧情”“从上一页续写”等要求只属于那个文档的任务，不能覆盖用户要求的新故事。

用一句话明确：**谁处在什么局面，什么可见事件改变了局面，本次交付停在哪里。**

- 完整短篇可用“目标→阻力→选择→结果”，日常故事可用“状态→细小偏移→被注意到→余韵”。
- 故事开头应建立情景和关系，让事件启动，留下具体可追问的问题；不在限定页数内强行解释全部线索或完成结局。
- 笑话、抒情或观察片段按体验选择落点，不强迫治愈小品加危机、每页反转，也不反复套用神秘包裹或纸条模板。

结构是工具，不是配方。[MediBang 剧情教程](https://medibangpaint.com/en/use/2021/07/mangatutorialforbeginners03/)

先写事件和必要对白即可。心理可以留在故事记录；需要视觉演出时化成眼神、距离、手势、道具或环境变化；例如“开始信任”可落实为松开包带、主动拉近空椅子。

<a id="comic-director.s02"></a>

#### 分开事件顺序与揭示顺序

先列实际发生什么，再决定读者何时看见什么。

| 记录 | 用途 |
|---|---|
| 角色此时知道什么 | 防止提前反应和动机缺失 |
| 读者此时知道什么 | 决定疑问、惊喜、担忧或误会 |
| 暂不展示什么，为什么看不到 | 安排裁切、遮挡、画外空间和揭示时机 |
| 本页留下什么，下一页如何承接 | 形成页间推动，避免机械截断 |

写实叙事的隐藏线索需要空间依据；梦境或超现实揭示按已建立的表现逻辑处理：全景已展示清楚的区域不能下一格凭空多出关键物。后续要操作的部件应先存在于物件设定中，其可见程度和强调强度按剧情安排，不必出现就给特写。契诃夫之枪用于管理被强调的细节与用途，不要求每件背景家具都成为机关；具体方法见 [连续性：固定事实、当前状态与可见范围](#comic-continuity.preamble)。

<a id="comic-director.s03"></a>

#### 按阅读节拍拆格

一个节拍是读者完成一次认识、情绪变化或有意义的停顿，不等于一句台词或一个动作。**每格通常冻结一个可读瞬间。**“伸手、抓起、转身、跑走”若过程都重要就拆格，否则选代表瞬间；不让普通单幅画面里的同一人物同时执行连续状态。

| 格子职能 | 应回答什么 | 可用画面 |
|---|---|---|
| 建立 | 在哪、谁与谁、有什么限制 | 空间关系清楚的全景、中景或局部 |
| 预示 | 什么即将变化 | 手接近开关、脚步进入、视线转移 |
| 关键 | 变化发生在哪一瞬 | 接触点、表情变化、关键物露出 |
| 反应 | 变化对谁意味着什么 | 眼神、手部松紧、身体退让 |
| 停顿 | 为什么需要等、听或迟疑 | 静止的手、空镜、同机位细小变化 |
| 揭示 | 哪个问题得到答案或部分答案 | 转向遮挡处、扩大景别 |
| 余韵 | 事件留下什么感受 | 新的共同动作、物件状态、空镜 |

“预示→关键→反应”可伸缩：动作清楚可省预示，突发事件可先冲击后补信息，也可停在反应，不强制三格。[SMA #003](https://www.manga-audition.com/japanesemanga101_003/)

- **删格检查**：删后因果、动机、情绪、线索或必要停顿受损吗？没有可说明的影响，考虑合并或删除。静默格若表现等待，可保留相同机位，只改变手指松紧、目光或光线等让停顿可读的细节。
- **强调检查**：大格、特写和长停顿提高读者期待。被强调内容有当前作用或后续用途吗？只需日常质感的细节可以降低强调。
- **换序检查**：交换两格会改变理解吗？若无影响，检查是否只是并列插画；并列比较本来就是目标则无须强改。

无对白不等于无作用，无新增剧情也可能承担尴尬或余韵，删格时把这些阅读作用一并考虑。

<a id="comic-director.s04"></a>

#### 按阅读需要分配镜头与出场

每格都塞同一组人物、同一房间和多个动作，可能让重要变化失去重点。按当前信息与情绪任务选择出场、镜头与环境；用户已指定的出场、镜头、可见细节和文字不为追求简洁而替换。

建立地点与关系后，可切到单人反应、接触点、道具状态、画外声音的接收者或必要空镜。双人关系可以由相邻格的视线与动作连接，不必每格双人。变化服务信息，不机械轮换全景、近景和俯仰角。

<a id="comic-director.s04.h01"></a>

##### 景别、格形与可见身体一起决定

- 远景用于路线、距离、环境尺度；中景用于身体互动；近景用于细节与情绪。建立镜头不强制为大远景，以手部开场后再补必要空间也可成立。
- 大格不等于远景，小格不自动等于特写。先确定要读清什么，再分配面积和长宽比；极窄格不宜同时承担两张脸、手部互动和长对白。
- 只写镜头中实际可见的特征、衣物和道具。脸部特写不列鞋裤，手部格不补整个人的发型；完整设定留在身份记录中。
- 大场景里“只伸入一只手”必须有可实现的来源：画边裁掉画外人物，手臂沿合理方向进入且够得到目标。无遮挡的俯视全景若无法隐藏其余身体，就调整机位、让必要前臂或上身入画，或改为接触特写。
- 两只手共同完成一次接触，可以是一个完整局部镜头。分镜记录手的来源、归属和当时动作；不以露出多少身体决定故事里有几个身份。

<a id="comic-director.s04.h02"></a>

##### 背景花在需要它的地方

建立情景、渲染氛围、空间变化或结局的大画面可保留必要背景。小反应格、手部格和物件格通常只留接触面或必要地标，例如手放在桌上就保留桌沿，门口回头就保留门边；已建立的整间房屋无需逐格重述。

同一空间可以用局部、反打、远近变化或同机位接续。按叙事目的选择：细微变化适合可比较的重复镜头，关系变化可能需要重新建立空间；必要地标、站位、动作方向和道具状态帮助读者把镜头接起来。

<a id="comic-director.s05"></a>

#### 用连接方式控制节奏

| 目的 | 合适的连接 | 先明确什么 |
|---|---|---|
| 清楚讲一件事 | 连续动作与反应 | 省略什么，关键因果是否可推断 |
| 比较处境 | 平行、对比 | 共同维度，是否同时 |
| 逼近与时间压力 | 交叉剪接 | 交替的新进展与会合点 |
| 延续感受 | 抒情空镜、感官细节 | 情绪从哪个事件而来 |
| 思想、梦、记忆 | 主观连接 | 入口、表现标志、返回现实的落点 |
| 不直说关系 | 象征、母题重复 | 物或动作在当前语境中的意义变化 |
| 等待、尴尬、微小变化 | 同机位重复 | 哪些不变，哪个细节变化 |
| 切换时空 | 形状或动作匹配 | 接续形状、方向还是位置，避免误认同地同时 |

名称用于导演判断，不必作为术语贴在交付稿里。重复机位本身有价值，应减少的是没有阅读作用的重复。

<a id="comic-director.s05.h01"></a>

##### 连续故事中的可选镜头组织

以下组织方法按本次剧情选用：

| 需要的阅读效果 | 可采用的组织 |
|---|---|
| 建立困境并引出选择 | 环境/处境 → 信息物件近景 → 人物反应 → 宽格收束；信息与反应分别承担工作 |
| 让揭晓有分量 | 先用小格交代到达、线索或短过程，再把重要空间/结果放进大格；过程需要几格就先在分镜中决定 |
| 连续对白中短暂停顿 | 近景之间插入一条远景或剪影横格，以距离、留白改变阅读速度；不强制每页使用 |
| 细节改变后重新交代关系 | 接触/物件局部 → 能看清双方关系的较远景；仍可见的既有状态继续保留 |
| 段落结束后落到情绪 | 旁白概括可省略的时间 → 远景重新定位 → 较大近景收尾 |
| 微小反应逐步变化 | 保留数格近似机位，让变化可比较，在有新信息或收束时才换景别 |

根据画面的阅读功能安排镜头，已定镜头与用户指定内容保持；后续是否准确呈现另行核对。

同时区分故事时间、阅读时间与情绪节拍：一秒动作拆五格可拉长时间，五个极简小格也可形成连击；长对白增加阅读时间，大格不必然慢。先决定快在哪、停在哪，再调信息密度、字量、面积、重复和间距。等格适合稳定日常和冷面笑话，不为“丰富排版”破坏它。[MediBang 同一剧情三种 Name](https://medibangpaint.com/en/use/2021/08/mangatutorialforbeginners05/)

<a id="comic-director.s06"></a>

#### 记录身份、状态与阅读位置

保留足以辨认角色的稳定称呼、每次出场的页与格、可见部位、站位视线、关键道具和当前状态。一个身份反复出现不变成新人；画面左边的人不是永久身份。按读序更新已发生、正在发生和仍然持续的事实；新动作不抹掉旧持物，未来结果不提前出现。

前景覆盖另记时刻、阅读位置和覆盖范围，与底层画格分开说明，不因为它横跨多个格子就拆成多个人。轴线与动作方向需要变化时，用地标、轴线上镜头、全景或角色移动帮助读者理解。几何见 [布局](#comic-layout.preamble)，状态见 [连续性](#comic-continuity.preamble)。

对白记录原文、说话者、位置与读序；旁白、内心话、声音和道具字分清来源。新创作允许提出合适文字；忠实改编、文字冻结或明确静默时保留边界，不新增台词或声效。

反读本次分镜，检查新动作、持续状态、镜头与文字是否相容。相似机位有阅读作用时保留；没有作用的强调可以收简，但不能顺手删用户已经明确的道具或服饰。只改某格时只核对与它相连的状态，不重导全篇。

<a id="comic-director.s07"></a>

#### 用户要完整文字分镜时的交付

完整新漫画、续写新页或尚未审阅的新增剧情，先按下列三部分交完整文字分镜，再接反馈；首次请求提到最终要 NAI 提示词，不等于跳过审阅，也不在这一轮附上生成字段。不能只交剧情梗概或页格计划而省略完整逐格稿。用户明确跳过审阅时按其要求接续：请求里有「直接给词」「只要提示词」「不用分镜」「直接能用的」这类说法就算明确跳过，由 `nai5-comic-writing` 在同一轮先出简稿、再转词。只要架构、梗概或单格修改时按其范围处理，不强制三部分。

<a id="comic-director.s07.h01"></a>

##### 一、剧情结构与必须保留的节点

说明起点、人物目标/关系、本段变化与落点。列出必须保留的用户设定、事件、对白、笑点或伏笔，以及它们的因果关系；新创作的连接与节点属于本次建议，不能冒充用户已确定的设定。只要求故事开头时说明留给下文的问题，不强行补完结局。

<a id="comic-director.s07.h02"></a>

##### 二、建议总页数，分格数及每页核心内容

给出建议总页数、每页格数与总格数，并逐页说明核心内容、节奏和页尾落点。总格数应与逐格稿相符。用户已指定页数/格数时在该范围内编排；必要时解释取舍，不擅自扩篇。条漫按约定的图片或阅读单元列出相应规划。

<a id="comic-director.s07.h03"></a>

##### 三、完整逐页逐格文字分镜

逐页列出页号、本页格数与作用，并写全每一格。可用逐格条目或可读的表格，至少覆盖：

- 每格的大小与位置，并用这些特征称呼它；审阅序号仅作辅助。有跨栏/破框时说明必要范围。前景覆盖另列位置、所跨画格、时刻和阅读位置，确有剧情需要时才补避让区域。
- 景别与视角、必要场景、人物站位和实际可见部位。
- 一个明确瞬间的新动作与表情、关键道具及仍可见的既有状态。
- 有文字时写原文、说话者/载体、位置与读序；标清对白气泡、旁白框或本次选择的载体。静默格省略文字项。
- 与下一格的衔接；页尾注明落点与翻页/下一阅读单元的作用。

完整新漫画的分镜交出后接用户反馈。用户已经明确说过要提示词时，确认后按确认版交 `nai5-writing` 与 `nai5-comic-writing`；这时收到明确可执行修改，落实后直接以修订版转换，无需再加一轮确认。用户只说想看漫画、只在改分镜，没说过要词时，修订后仍停在分镜，把改动和牵连的节点交回去，等用户说转换再转——「想看一个漫画」不等于「本次已请求转换」。范围外的连带改动仍先列出、不擅自改。反馈仍在讨论、关键选择未定或明确要求先看修订分镜时，继续完善分镜。已定稿、已有确认或明确要求跳过审阅时可直接转换，不重发已有导演稿；只改指定格或文字时按本次范围处理。

<a id="comic-composition.s03"></a>

#### 镜头连接的补充例

<a id="comic-composition.s03.h01"></a>

##### 按信息功能组织阅读

| 编排目的 | 可采用的连接 |
|---|---|
| 从目标引出行动 | 交代目标 → 看清线索 → 人物判断 → 开始回应 |
| 给结果留分量 | 短格呈现必要过程 → 较大画面揭示变化 |
| 对话中短暂停顿 | 近景问答 → 远景或空镜 → 回到关键反应 |
| 让状态变化可理解 | 物件局部 → 交接或放置 → 较远景延续新状态 |
| 表现微小递进 | 近似机位重复，逐格改变真正重要的信息 |
| 段落收束 | 概括可省略的时间 → 重新定位空间 → 表情或动作余韵 |

例如修理一盏台灯：先看见故障，再检查接点，短暂停顿后试亮，最后以人物反应收尾。具体格数取决于哪些步骤必须看清，不把整个过程塞进同一瞬间，也不为套表格增加无作用的镜头。


<a id="method-ideation-comic-layout"></a>

<a id="comic-layout.preamble"></a>

## 页漫与条漫编排

先确定媒介、方向与交付页数，再选择格型。纸本跨页、分开图片与手机条漫的提前可见范围不同。[Manny Guevarra 的页漫／条漫比较](https://tips.clip-studio.com/en-us/articles/9420)

<a id="comic-layout.s01"></a>

#### 用阅读任务分配页面

- **入口**：第一眼从哪里开始，需要先知道什么。
- **重点**：这一页最应记住的变化，为它分配面积、对比和留白。
- **出口**：自然停顿或推动下一页的问题，不要求每页悬崖式结尾。

用户指定的页数、格数、全彩/半黑白/黑白、四格或条漫优先；未指定色彩的新漫画默认全彩，色彩服务本次表现意图。未指定格数时按内容、节拍与可读性安排，不预先凑到某个范围。阅读顺序默认从左往右、上→下；右→左只在用户指定或改编原作时用。四格默认 2×2，读序左上 → 右上 → 左下 → 右下，竖排等版式只在用户指定时用。本次另有明确读向或已确认分镜时按其约定。

缩略图阶段先画矩形、人物轮廓与气泡占位，检查“格→脸／手／线索→文字→下一格”的路线，再决定大格、插格或破框。若读序出现岔路，先移动格子、气泡或越界轮廓，让上一格的出口接向下一格的入口，再补必要说明。[Steve Ellis 布局教程](https://www.clipstudio.net/how-to-draw/archives/160963)

页号或审阅序号可用于交流，位置与大小帮助读者理解页面。先确定叙事格，再描述行组、并排、上下、宽窄等关系；独立插格计为画格，覆盖人物单独说明，不为套版式增添无作用的镜头。边框颜色、留白、分隔线和装饰随本次美学需要决定，用户的明确指定保留。

<a id="comic-layout.s02"></a>

#### 格形必须容纳镜头

画格面积、长宽比、景别和视角是相关但不同的决定。先明确可见身体、接触点、背景信息与文字空间，再配格形。

| 任务 | 可考虑的格形 | 先检查 |
|---|---|---|
| 建立环境与相对站位 | 较大横格或主格 | 背景是否必要，人物是否仍清楚 |
| 横向伸手、递物、两端接触 | 横向细节格 | 交互是否同处一格，手臂来源与距离是否成立 |
| 站姿、落下、上下距离 | 竖格 | 身体与动作方向是否被无故截断 |
| 单人反应、物件线索 | 小格或适度插格 | 视觉重点是否单纯，文字是否挤占表情 |
| 情绪停留或重要揭示 | 较大面积、留白或全宽格 | 强调是否值得，是否只是凑版式放大无信息局部 |

大格可以是脸部近景，小格也可能是极简远景，不机械绑定。手部局部也可放大强调关键接触，但来源和裁切必须合理，不能在无遮挡的完整俯视场景中要求其余身体消失。

变化来自主次、行组和适合内容的长宽比，不必不断斜切。组内间距近、组间间距远用于明确阅读分组，不是“竖缝永远比横缝窄”。小格背景以必要接触面或地标为限，复杂空间集中于确有建立、氛围或变化任务的格。

<a id="comic-layout.s03"></a>

#### 区分裁切、破框、跨栏与前景覆盖

| 手段 | 含义 | 导演阶段辨别 |
|---|---|---|
| 画外／裁切 | 身体存在，但超出相机取景 | 可见部分、进入画边、动作距离 |
| 角色破框 | 身体一部分越过所属格边线 | 哪个部位、哪条边、进入哪块留白、属于哪个瞬间 |
| 跨栏画格 | 一个格横跨版面两栏或更多栏 | 只算一格；起止位置、读序和其他格边界 |
| 无框或叠格 | 去掉边框，或独立格叠在主格附近 | 各格时刻、读序、轮廓与文字归属 |
| 前景覆盖人物 | 一个连续的无框人物形象叠在选定画格前方，遮住它们的一部分内容与格线 | 覆盖位置与范围、哪些格在其下方、轮廓遮挡关系、时刻与读序；不另围成大格 |

同一角色在前后格出现，不叫一个角色跨两格；同一动作的两个时刻也不能被破框效果粘成一具身体。

其他格型按叙事需要选用：插格补一个反应或线索，须标清它在主格之前还是之后；环境底图承接若干小格时，底图负责空间、小格负责时序；无框与留白可以提供停顿。同时使用时，分别说明各自补充的时刻或信息，并给读序留出清楚的入口。

心理黑底、回忆边框、装饰图形与面部叠像属于表现层，要有清楚的开始、结束和现实锚点。黑底不自动代表夜晚，叠像面孔不等于现场多了一个巨人；若直出反复误解，再按用户要求考虑分层资产与后期组合。

<a id="comic-layout.s03.h01"></a>

##### 破框先做四个决定

1. **阅读目的**：动作冲出、突然抬头、亲近或情绪放大等。无作用时保留完整边框；用户要求合适破框时，选已有动作能自然承载的格。
2. **几何来源**：保留躯干、关节或明确局部来源，让越界部位属于本格人物。“手伸出框外”不能代替姿势与接触设计。
3. **越界区域**：例如右前臂越过本格右边线、伸入页面右侧留白。为它留空间，不遮邻格入口、气泡或关键线索。
4. **时间归属**：越界仍是来源格的同一瞬间。若接触物件，该物也属于同一空间，不能伸进下一时刻的画格抓物。

<a id="comic-layout.s03.h02"></a>

##### 前景覆盖：可选，不限定排列或覆盖格数

需要突出动作的释放、情绪停顿或过程后的状态时，可将一个完整连续的无框人物影像叠在若干画格前方。区别在于**底层画格延续到人物后面，格线在其轮廓处被遮断**；若只在旁边留出独立大格再让耳朵、袖子出框，得到的是另一种版式。

- **按情节定范围。** 可以位于左、右、上、下、中央或斜向展开；可只跨相邻两格、某个行组，也可延伸到整页。底层可上下、左右或混合排布，人物可为全身、半身或近景。不要把已用过的“右侧覆盖三条横格”固化成默认模板。
- **先定时刻与阅读位置。** 覆盖人物可以放大既有瞬间，也可以承载过程后的一个收尾节拍；在文字分镜中说清先读哪些格、何时读它。影像本身只画一个瞬间，不让同一具身体在被覆盖的不同时间画格中继续执行动作。
- **为关键内容让位。** 导演时把底层动作、表情、对白与线索安排在可读区域，不限于左侧。分镜按需要交代覆盖范围和避让，不输出与本题无关的固定保留清单。
- **按需说明遮挡。** 无框覆盖已表达前后叠置关系，通常不再逐条描述格线如何隐藏或保留；实际呈现误成独立大格时，再根据对应底稿定位误解。坐姿、倚靠等可带上必要座沿或接触面。

这是可选的视觉强调；若会遮住揭晓、抢走读序或压缩动作空间，就调整范围或采用普通分格。分镜中将“底层若干格＋覆盖画面”分别列明，不把覆盖影像因穿过多格就拆成多个人物。

<a id="comic-layout.s04"></a>

#### 页间承接：哪些内容同时可见

先判断读向和是否为同一展开面；不要凭奇偶页号推断翻页点，起始页、装订和阅读器都会影响配对。

- 页尾可留未揭晓的反应、动作起势、画外来声或未回答的问题。故事开头让下文有明确追问即可，不急于揭开所有答案。
- 真正依赖翻页的答案放在翻过去才能看见的位置。同一展开面另一侧的大揭示可能已被余光看到。
- 两张独立生成的图不必同角度重复完整房间。用局部、反打、反应和物件状态衔接，以必要锚点保持关系；见 [漫画导演：先写故事，再安排读者看见什么](#comic-director.preamble) 与 [连续性：固定事实、当前状态与可见范围](#comic-continuity.preamble)。
- 双页大图的脸、字与关键接触点避开中缝。出血和裁切按目标规格处理，不能仅凭文字说明声称已完成精确排版。

答案也可留在同页，不硬凑翻页悬念。SMA 的右读、无对白属于比赛要求，不是通用规则。[SMA 页尾引导](https://www.manga-audition.com/rules-guidelines/)

<a id="comic-layout.s05"></a>

#### 条漫按手机可见区域编排

竖长画布由滚动可见区域组成。先决定当前屏能看到什么，再安排屏下揭示；不把页漫格数偏好套进条漫，也不把整话机械压成一张极窄密集的图。

- 垂直距离可提供停顿、时间省略与转场，固定像素间距不是通用节奏单位。
- 下落、楼梯、雨、烟与视线可引导滚动，前提是它们属于当前场景。
- 惊喜的答案留在此前视窗之外，避免上一屏全景提前暴露。
- 手机横向并排小格易缩小脸与字，按目标宽度试读；必要时拆为顺序格，保留因果与同时关系。

这些是创作者的方法，不是平台强制配额。[69Michi：Webtoon 101](https://tips.clip-studio.com/en-us/articles/4143)

<a id="comic-layout.s06"></a>

#### 文字从分镜阶段占位

文字与画面共同编排；静默格可以省略文字项，不必逐格列出无字声明。

拟声词也是日常分镜可主动使用的表现手段：可用轻微环境声渲染气氛，用接触或运动声配合动作，按情绪节奏选择字量与强调程度。不必等用户提供具体声音词；只为已有画面选合适的声音，给需要停顿与留白的格子保留安静。创作阶段可一并编排，不逐格机械添加。冻结文字、忠实改编或只改指定部分时，不新增声效。

| 类型 | 来源与占位 |
|---|---|
| 对白 | 对白气泡；说话者、原文、顺序、位置与尾巴指向 |
| 旁白 | 旁白框；原文、所在格与位置 |
| 内心话 | 声音身份与用户选择的载体，不自动当成对外说话 |
| 声效 | 声效文字、声源、原文和方向，不自动放进对白气泡 |
| 道具上的字 | 写在便条、卡片、标牌等实体上，不改成旁白框 |

同格多人时让说话归属清楚，共享旁白与声效只在需要的位置出现。用户选择后期排字时可单列文字清单与留位，不把它强制成所有漫画的制作方式。

先说者的泡放在先读位置，尾巴避免交叉，不遮脸或关键手势。文字拥挤时检查台词是否复述画面、是否需要反应节拍；不按固定气泡数量删掉用户必须保留的原文。原文必须保留时，可增加文字区、移动人物，或在允许调整格数的范围内另安排反应格。

中文行列顺序、字泡内边距和最终显示大小需实际检视；英文排字传统只借鉴归属与布局，不直接套用标点和字体惯例。[Blambot](https://blambot.com/pages/comic-book-grammar-tradition)

<a id="comic-layout.s07"></a>

#### 布局记录与试读

按实际需要记录载体、读向、布局、阅读路线、重点、越界范围、文字留位和时序。不是每次交表；完整分镜直接承载这些内容即可。旧版包含角色框操作的记录示例已迁到写法，不成为这里的创作模板。

1. **缩小看**：起点、行组、下一格和重点清楚吗？格形装得下镜头与文字吗？
2. **按序看**：动作、人物和物件状态接得上吗？破框混淆时间吗？揭示提前可见吗？
3. **图文对照**：画面完成了应当可见的动作吗？文字补充了什么？是否被越界部分遮挡？对白驱动故事不要求去字后解释全部情节。

未看到成品时只能审查脚本与布局；实际格形、破框、字与连续性仍需看图确认，不声称文字方案已经完成视觉验证。


<a id="method-ideation-comic-continuity"></a>

<a id="comic-continuity.preamble"></a>

## 漫画身份与状态连续性

连续性记录故事中的事实、当前状态和镜头所见。不需要把整份状态表贴给用户，也不把所有画外设定塞进每格。

<a id="comic-continuity.s01"></a>

#### 建立够用的连续性记录

| 层 | 记录什么 | 落实到分镜时 |
|---|---|---|
| 身份 | 发型/原色及本次显示颜色或明暗、体型、种族特征、辨识配饰 | 只取实际可见项；不能为省词随意改身份 |
| 本场服装 | 轮廓、领口、袖长、层次、下摆、原色及本次显示颜色或明暗 | 同一可见部件复用相同描述；被裁切/遮住的部分不写 |
| 道具结构 | 数量、轮廓、开合方式、提手/附件等剧情必需项 | 同一道具复用短小固定称呼和结构，不能后文换一种机构 |
| 状态 | 开/关、覆盖高度、归属、所在位置、手的接触、内容物是否可见 | 逐格更新；变化由动作或可理解的格间省略支撑 |
| 空间 | 必要地标、人物相对位置、视线与运动方向 | 换机位仍能理解空间，不要求每格重画全套布景 |

用户已指定的服装、饰品、道具结构、台词先完整记录，不能以“与剧情无关”为由删除。未指定部分只记录对故事或辨识有影响的细节，不为一个背景杯子编型号。

- **用户要求本格可见**：将该细节作为镜头条件保留；既定镜头确实装不下时明确指出冲突，不静默裁掉或替换。
- **事实仍在但本格画外**：留在连续性记录，当前分镜描述省略；再次入镜时按原事实恢复。裁切不改角色、服装或持物事实。
- **未指定部分**：按剧情需要简洁补足，不擅加身份特征或复杂配饰。

用户只改某一处或冻结原文时，除目标改动外保留原来的文字、空格与标点；颜色和连续性检查不能成为无关改写的理由。复杂段落可用“页号及画格位置/大小／可见范围／固定锚点／当前状态／承接动作”快速核对。

<a id="comic-continuity.s01.h01"></a>

##### 同页逐格的持续状态

每格写本次新动作，也写先前已成立且在当前镜头中仍可见的状态。分镜不能只记录变化，让上一格的持物、接触或位置凭空消失。

- 按故事先后区分“尚未发生、正在进行、已经保持”的状态。多个部位或物件依次操作时，各自保留当前阶段，不把后一步的结果提前混进前格，也不把前一步重置。
- 例如右手已拿起钥匙，接着左手拿杯子：两手入镜时同时写右手仍持钥匙、左手拿杯子。改为脸部特写时省略画外的手与物；以后重新入镜，再按当时状态写明。裁切只改变描述范围，不改变故事事实。
- 需要交代空缺时，直接写简短状态，如“空着的左手”；不列举这只手没有拿哪些物品，也不为避免未来物件提前出现而逐项点名排除。只写与本格有关的当前状态。



从实图借鉴连续性时，分开检查信息顺序、空间关系与可见状态：对白接得上不等于左右手、物件或距离都已连续。局部细节后拉远可重新交代关系；旁白可以压缩无须展示的时间，但不能替代读者必须看清的状态变化。段落连接可参考 [漫画导演的节拍与连接](#comic-director.s05)；更换镜头不会重置已经成立的状态。

<a id="comic-continuity.s02"></a>

#### 契诃夫之枪：先建立功能，再让它生效

- 后面要拉拉链，前面出现的包就要是拉链包；后来需要纸条，就应有合理出现或发现的过程。
- 一个被特意强调的结构、道具或声音，应承担动作、线索、人物塑造、气氛或节奏作用。只增加绘制负担却没有作用的强调细节，删掉。
- 这不是“所有背景与角色饰品都必须推动情节”。必要环境与身份锚点可以保留；故事开头的伏笔允许在后文兑现，不能为了立刻回收而把开头写成结局。
- 剧情依赖物件功能时，先定它如何被操作，再补相应外观：要从口袋取物，就交代口袋所在一侧和手能到达的位置。仅作装饰的标签或吊坠可以保持背景程度，无需另编事件。
- 道具辨识优先复用已确定的轮廓、开合方式和关键线索；发生漂移时，先检查这些描述是否一致。新增补丁、刺绣或吊牌只在本次设计确有需要时加入，避免增加逐格保持的负担。

**包的修正示例（不是所有包的默认设计）：**

例如固定为“小型长方形布包，两条短提手，顶部一条拉链”。第一次包口可见时建立顶端拉链；若后文操作拉片，先确定单个滑块及所处端。按动作顺序写“拉链闭合→手握拉片拉开一段→开口露出内容物”。可见的固定结构在相关格重复，状态不同就改状态，不改包型、提手或开合机制。

如果故事无需拉链，用敞口包即可；如果已经明确是按扣包，就延续按扣的开启动作。不能给按扣包临时装上拉链。吊在提手上的纸签也不能无故变成缝在包内的标签。

先核对原稿，区分“前后描述不一致”“遗漏关键结构”和“描述一致但模型漂移”。用户给的实图是结果证据，不等于对应的底稿；区分底稿矛盾与实际表现偏差。

<a id="comic-continuity.s04"></a>

#### 换装和覆盖物需要状态连续

用户要求简单日常服时，先确定本题人物的服装基底，再分镜。优先少层次、易辨轮廓和不同明暗；领口、袖长、裤/裙轮廓等固定下来。确需新设计时可接 `oc-costume-design`，带回已定服装继续本次分镜；已有服装直接沿用，只改服装时交替换描述，不额外重审故事。用户要转换提示词时另接 `nai5-writing`。

不要把一次换装写回 OC 的永久设定，也不要把“所有漫画必须穿短袖”变成规则。

**手部校验：** 短袖上衣的袖口在上臂；手和前臂特写若没有拍到上臂，就只写裸露前臂，不继承旧星纹长袖或西装袖口。

**毯子校验：** 从颈下近景切到双人远景，覆盖边沿仍须落在同一身体锚点，例如颈铃下方/上胸。若要降低到腰部，先安排放下毯子、坐起或另一人拉动等能解释变化的动作；换景别本身不是毯子滑落的原因。盖住的衣服留在事实记录里，当前分镜只描述实际可见部位，避免把显示衣服与保持覆盖同时当作取景要求。

写清“当前看得见什么”，不把未来动作后的状态提前混进同一格。物件数量、谁拿着它、哪只手接触和位置同样如此；已成立的状态在后格仍入镜时继续写明，不能只写本格的新动作。

<a id="comic-continuity.s05"></a>

#### 场景连续与镜头选择

同一房间反复出现时，必要地标、站位和物件状态应连续。根据阅读目的决定何时需要重建空间：

- 引出情境、渲染气氛或重要结果的大格，给够建立空间所需背景。
- 反应、手部、道具等小格尽量省背景，必要时留一个桌沿/门边等空间锚点，不重复整套房间。
- 跨页用合适的近景、反打、局部取景和视线连接，避免为了交代相同信息再画同机位全景。
- 若剧情依赖前后对照，或转场确实需要重新定位，则保留必要全景；不要为了遮掩漂移破坏读者理解。
- 换角度不能掩盖事实矛盾：开合、覆盖高度、衣服结构和道具数量仍要对得上。

镜头变化服务读者理解，不为掩盖生成差异而改掉既定镜头。没有修改后的实际图时，只能确认稿件内部一致。


<a id="ideation-comic-color"></a>

### 色彩表现与身份事实分开

新漫画未指定模式时默认全彩；续页和局部改稿延续本次已定模式，用户本次切换优先。黑白、半黑白或局部保色是表现选择，不改变人物、服装和道具的原色事实。保留原色记录，同时确定画面上需要连续的明暗关系、对比和保色范围；浅发与深衣不能因为换页就颠倒。

默认半黑白仅头发与眼睛保色，其他部分灰阶；用户明确另外的范围时按本题范围。黑白保留轮廓、材质与明暗，不等于删除部件。具体如何转成词句与检查全部字段由 `nai5-writing` 处理，本阶段不生成风格串或排除词。

<a id="costume-design.preamble"></a>

## 服装设计

目标是设计属于本次角色和表达意图的服装。轮廓、结构、配色、材质与穿着状态共同表达身份、气质或纯粹的审美；日常可穿、舞台夸张和幻想造型可以有不同逻辑。不因现有标签库或后续实现难度缩窄创意。

<a id="costume-design.s01"></a>

#### 日常构思方式

新服装、普通换装和开放式改稿都将[设计工具箱](#costume-design.s05)的方法纳入构思，无需等用户说“新奇一点”。读完角色与需求后，考虑哪些路径能表达本次核心印象，再比较少量有实质差异的方向，选定后细化轮廓、配色与部件。这是内部思考习惯，不要求每次输出方法表或多个方案。

方法可以单独使用，也可以自然组合；不要求每套设计混搭、加入道具、达到某个主题数量或用遍方法表。用户指定的风格、认可的部位和局部修改范围决定探索边界。已定设计不重新展开；要转成词句可直接接 `nai5-writing`。

<a id="costume-design.s02"></a>

#### 建立设计简报

从当前用户资料、参考图和实际启用的 OC 资料提取相关约束；未知身份、性格与外貌不当作事实。设计所需但未锁定的部分可以提出明确主案，新增设计与用户设定分清：

- 身份：年龄感、职业/阵营、阶级、公开身份与真实身份。
- 性格：克制或张扬、亲近或疏离、整洁或随性、实用或仪式化。
- 世界：年代、地域、文化来源、科技/魔法水平、气候与资源。
- 场景：日常、工作、战斗、旅行、庆典、舞台或睡眠；需要完成哪些动作。
- 身体：身高比例，以及头发、手臂和腿脚会与帽兜、领口、袖口、手套、袜靴发生的可见关系；尾巴、翅膀、角、兽耳等幻想特征作为轮廓锚点记录。
- 识别锚点：主色、物种特征、标志图案、关键饰品、不可改变的角色设定。

把简报压成一句设计命题：

> 为【身份与性格】的角色，在【世界与场景】中设计【服装原型】，通过【轮廓/材质/图案】表达【核心印象】，同时满足【动作或身体约束】。

设计阶段以已有的固定外貌、体型、物种特征和识别锚点决定领口、头饰、配色与轮廓。OC 资料仅在用户提供或实际启用时使用；没有库时不阻塞，也不补造缺失外貌。只在帽兜、领口、袖口、手套、袜靴确实影响头发或四肢时处理穿着关系；默认不为翅膀、尾巴、角或兽耳补充开口、分片或防穿模结构。本阶段交服装设计，不默认附衣物提示词。设计定稿后若用户要文字表达，带着已有服装与本次终点接 `nai5-writing`。

<a id="costume-design.s03"></a>

#### 按设计问题拆解参考

需要参考时，从能解决本次问题的来源取材，例如真实服装史或博物馆、当代服装/工装、动漫游戏角色或舞台服，不为凑来源数量扩展已定稿。把有用的参考按以下维度拆解：

1. 概念：身份、故事与情绪。
2. 轮廓：长短、宽窄、重心、外扩位置、露肤分布。
3. 色彩：主色、辅色、强调色，以及明度和冷暖关系。
4. 材质：硬/软、厚/薄、哑光/反光、挺括/垂坠。
5. 装饰：图案、滚边、褶、扣件、绳结、徽章、首饰。

要理解具体结构，可搜“时代/地区＋具体衣类”“职业＋制服”“动作需求＋防护/收纳”等能解释结构的资料。

<a id="costume-design.s04"></a>

#### 先定轮廓和视觉层级

从[设计工具箱](#costume-design.s05)选择适合简报的方法，比较少量在轮廓、搭配关系、材质或穿法上有实质差异的方向，再选主案；数量随任务规模调整，明确的局部修改可直接处理。检查：

- 一眼可读的服装原型是什么：制服、礼服、工装、猎装、祭服、运动装、街头装等。
- 重心落在头肩、胸腰、胯部还是腿脚；宽窄变化是否呼应角色性格。
- 主形、次形、强调形是否形成清楚的面积与视线层级。
- 发型、耳角、尾翼与衣服是否争夺同一块轮廓空间。

<a id="costume-design.s05"></a>

#### 灵活选择设计方法

以下方法用于日常构思，属于开放的工具箱，可独立使用或组合，没有优劣次序，也不要求逐项执行。优先从熟悉、容易辨认的形制和物件出发，让设计落在能画出的具体变化上。

| 方法 | 适合解决的设计问题 | 可见的操作示例 |
| --- | --- | --- |
| 服装与异质配件、道具搭配 | 服装本身已经成立，希望以直观反差建立身份或故事 | 普通雨衣配死神镰刀；街头装搭王冠与巨剑。各部件可以保留原本形制，协调比例、配色或携带关系即可成立。 |
| 跨风格单品组合 | 希望通过穿搭关系改变整体印象 | 复古衬衫、运动夹克与工装下装共同组成造型，用长短、松紧和色块关系协调。 |
| 剪裁与结构重组 | 希望主单品自身具有新的轮廓或结构 | 在连帽外套上借用水手领结构，把围裙的围裹方式用于外层裙片；保留清楚的主形制。 |
| 材质、工艺或功能转换 | 喜欢现有形制，希望改变它的触感、用途或身份感 | 以柔软针织制作有军装分割线的短外套；把礼服刺绣用在帆布工装口袋上。 |
| 比例与尺度变化 | 希望在较少部件中建立可爱感、力量感或重心 | 通过宽大上装与紧凑下装改变身形节奏；用小角色与大工具的尺度差形成反差。 |
| 穿法与场合错位 | 希望服装表达角色性格或生活习惯 | 正式衬衫卷袖并松开领口，制服外搭居家针织开衫；用穿着状态表现随性或亲近感。 |
| 图案与形状转译 | 希望角色母题进入衣服自身，而非只挂一个饰品 | 将兔耳形压缩为成对的长口袋盖，把花瓣节奏用于圆弧裙摆；保留少量可读特征。 |
| 单一风格内精炼与减法 | 风格已经合适，希望提升整体美感和辨识度 | 调整领口、衣长和色块面积，删去争抢焦点的挂饰，使一个已有轮廓更鲜明。 |

主题可以来自年代、职业、亚文化、生活场景或审美风格；数量、职责和影响范围保持开放。一个主题可以作用于多处，多个主题也可以作用于同一部件。整体搭配与部件内部融合都是有效做法，内部融合更深并不自动意味着设计更好。

例如“雨衣＋镰刀”的普通雨衣与熟悉武器可以直接成立。若本次设计需要，也可以进一步调整弧线或材质来呼应；这属于可选发展，不是合格前提。“街头装＋王冠＋巨剑”同样可以靠完整单品之间的气质与尺度反差成立，不必把王冠或剑的图案重复到每件衣物上。

选择时检查：本次角色印象由哪些可见变化表达；比例、色块、线条、材质或故事关系是否足以让组合协调；第一眼能否看清整体与焦点；增加或删减哪一项会实质改善画面。无需强求每个单品都有共同纹样或专门的连接细节。

例子用于说明方法，不作为以后换装的固定素材池。连续设计时，根据用户希望保留和改变的内容选择方法；用户要求新方向时，探索与上一套有实质差异的思路，已认可的方法与单品仍可使用。无需为轮换而改变成功选择。整体已经好看、贴合角色且满足本次变化需求时即可定稿。

<a id="costume-design.s06"></a>

#### 组成一套服装系统

把部件放到身体上，说明彼此的层叠、长度与连接：

- 基础原型：决定第一印象的类别。
- 主角单品：承担最大辨识度的外套、裙装、胸甲、披肩或连体装。
- 支撑层：内搭、领口、袖型、腰封、下装和必要的过渡层。
- 腿脚系统：腿部露肤、袜/护具、鞋型与动作需求共同设计。
- 标志配件：按本次设计与用户清单保留包、帽、武器挂点或首饰，明确各自位置与视觉作用，不设配件配额。
- 开合与收纳：扣、拉链、系带、搭扣、口袋、挂环的位置需要说得通。

配色采用“主色＋辅色＋少量强调色”。标志母题可在领口、腰侧或鞋面等合适位置呼应，通过尺度或功能变化形成节奏，不要求填满位置或凑重复次数。

材质优先形成一组主要对比，例如硬皮革/软针织、哑光棉/亮面金属。例如硬皮革的边缘保持挺直，软针织在腰肘处聚褶，金属扣的亮点集中而棉布受光较柔；按材质调整具体部位。

细节数量不等于设计质量。主轮廓、层级和核心识别点成立后，先停下来检查整体；核心识别点可以来自服装结构、穿法、材质、图案、发饰、鞋袜或道具，不预设类别。新增装饰按轮廓、配色、母题或搭配效果取舍；用户明确要求的具体部件先保留，通过层级和位置协调，不以“过载”自行删掉。可爱感优先通过圆润轮廓、宽松与紧凑的比例、柔软边缘、清楚色块和少量易读图案表达，而不是继续叠荷叶边、扣件和挂饰。若要用巨大武器表现娇小反差，武器应明显大于角色但仍保留清楚的握柄、刃部或击发结构，避免大到像建筑或柱子。

<a id="costume-design.s07"></a>

#### 让衣服表达身份、生活与表现逻辑

用可见证据表达身份，而不是只说“高级”“神秘”或“精致”：

- 阶级和资源：面料幅宽、刺绣密度、修补方式、金属件质量。
- 职业和习惯：磨损、污渍、卷袖、惯用侧口袋、工具挂点。
- 气候和活动：通风、保暖、防水、活动量、坐骑或战斗需求。
- 穿着关系：说明长发如何位于帽兜或衣领内外，宽袖是否妨碍手部动作，手套、袜子和鞋靴怎样衔接。幻想附肢默认遵循二次元视觉逻辑，不主动为翅膀、尾巴、角或兽耳添加洞口、分片、系带或加固边；只有用户把接口本身设为可见设计重点时才展开。

“舞台装/战斗装看起来合理”和“日常能穿”是不同目标；根据场景选择，不必把所有设计都合理化成现代日常服。

<a id="costume-design.s08"></a>

#### 设计换装与角色衣橱

先区分不变量和变量：

- 不变量：角色配色、物种特征、标志母题、关键饰品、某种固定线条或开口语言。
- 变量：服装原型、季节、场合、裙裤比例、材质、外套长度、正式度。

保留用户要求与角色辨识所需的锚点，变化幅度由本次任务决定。主题完全不同的换装应呈现清楚的新印象；同系列衣橱可以延续版型与母题；配色变体或局部精修也可以是完整的设计目标。根据目标判断变化是否有效，不规定每套必须保留或改变多少项。

<a id="costume-design.s09"></a>

#### 根据出图反馈迭代

先把用户给出的图与对应设计稿对照。设计本身满足要求而图没表现出来，属于实现或写法问题，不因此自动重设计；用户要调整设计时再判断是哪一层：

1. **轮廓不对：** 先调整量感、长度与分割，或更换基础服装原型；根据用户认可的部分选择改动幅度。用户喜欢的原型可以保留，并用[设计工具箱](#costume-design.s05)的其他方法发展。
2. **气质不对：** “可爱”被硬质棱角、笔直分割和沉重配件压住时，先改主轮廓、边缘形状与比例。
3. **道具读错：** 弩炮变成柱子、复杂机关无法辨认时，改用更简单的标志性几何，或直接换成另一类道具；不要持续堆结构词。
4. **携带关系不对：** 包、剑、镰刀等位置错误时，明确写肩扛、斜背、手持及左右侧，写清接触点和携带方向，例如背带斜跨胸口、包落在左胯，或握柄靠右肩、刃部朝身后。
5. **主题仍然普通：** 回到[设计工具箱](#costume-design.s05)，选择能改变第一印象的方法。可以保留服装而换用异质配件或道具，也可以调整单品组合、结构、材质、比例、穿法或母题；不预先固定改哪个部位，也不要求增加主题数量。

保留用户明确认可的部分，只替换导致失败的层级。按本次反馈确定改动范围，例如服装原型、轮廓重心、主题语汇的落点或核心识别点；用户允许调整的复杂部件可简化或替换；锁定部件先修表达、位置或可见关系，需要改设计本身时提出具体替代建议，不把局改扩成删件。没有实际图像反馈时不宣称已验证生成效果。

<a id="costume-design.s10"></a>

#### 理解既有偏好并判断是否需要变化

角色库记录过去采用的造型。蝴蝶结、蕾丝、短裙、袜类、制服感等元素反复出现，可能与用户偏好、角色设定或既有生成方式有关；频率本身不能判断设计质量，也不足以认定这是需要纠正的惯性。当前要求、参考图和用户明确反馈优先于从频率推测出的偏好。

- **允许有价值的重复。** 熟悉的单品和组合可以维持审美连续性与角色辨识度。同样的“百褶裙＋长袜＋玛丽珍鞋”可以通过比例、配色、穿法和搭配形成适合不同角色的结果；整体成立时可以直接采用。
- **根据具体问题调整。** 需要警惕的是忽略当前需求的自动套用，例如不同性格与场合仍得到同一种气质，或用户明确要求的新印象始终没有出现。先定位不匹配的部位或关系，再选择修改方法，不将原因直接归结为某一服装类别。
- **扩展选择范围，保留取舍自由。** 裤装、裙装、连体装、不同鞋型等都属于候选。按轮廓、角色气质、色彩、搭配关系和用户意图取舍，不设品类配额，不因少见而优先，也不因常见而排除。需要新意时，可以从熟悉元素中继续发展。
- **承认纯审美的理由。** 不对称、系带、蝴蝶结等可以通过视觉平衡、节奏、垂坠或俏皮感成立，无需一律赋予实用功能。根据它在整体中的可见效果判断保留、调整或删减。

这些判断融入日常构思，不要求逐件向用户论证。目标是让每次选择回应当前设计，而非追求衣橱统计上的均衡或最大差异。

#### 交付格式

按用户要求的详略交一个主案或所需方案，以下为可选组织项，已有答案不重复确认；不机械填空、补背景故事或附提示词。只改某部件时仅交该部件。

```text
设计命题：
角色识别锚点：
服装原型与场景：
轮廓与重心：
配色层级：
单品拆解：
材质与褶皱：
母题与配件：
开合、收纳与头发/四肢关系：
可见的角色故事：
变体建议：
刻意避免：
```

需要验证整套服装时可从正面、背面、侧面与动作状态观察；只要局部设计时检查相关部分即可：轮廓是否仍可读，衣服如何穿脱，头发是否被帽兜或衣领意外吞没，袖口和鞋袜是否妨碍四肢，装饰是否掩盖视觉焦点。翅膀、尾巴、角和兽耳只检查是否保留角色辨识度，不补写穿模解决方案。

#### 用户材料的叙事经验

归档《分镜脚本提示词（例）》支持“剧情节点—页级节奏—逐格镜头、文字和衔接”的制作顺序，以及避免没有作用的连续大头、让静默格有意义、页尾与下页协作等方法。它原来用于剧本改编，原件中的不新增剧情、续写位置和读向并非所有原创任务的要求。

归档反馈里，毯子边沿漂移、包的开合机构改变、连续持物丢失、灰阶明暗变化，分别促成当前的持续状态、道具结构与明暗连续性检查。这些是局部经验；完整提示词、全部设置与批量结果并不齐全，不提供成功率保证，也不称本轮重看了视频、图片或新增生图验证。
