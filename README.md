# NovelAI V5 完整构思与写法 · v1.2a-nightly

这是 `v1.2a-nightly-20260914` 的完整方法包，以本项目 v1.1 通用写法为基准，整合普通插画、漫画与四格、OC 服装设计和提示词转换。本版为 nightly 预发布；v1.1 继续作为正式版。

## 使用

将 [NAI5_All_Prompting.md](NAI5_All_Prompting.md) 全文交给聊天助手作为参考，再提出本次任务。支持技能目录的环境可通过 [SKILL.md](SKILL.md) 入口使用同一完整稿；当前方法不依赖其他安装包。角色设定由用户按需提供或明确启用，包内不包含私人 OC 库。

先看正文开头的任务与共同契约，再读对应章节：

- 普通完整插画：主串组织动作、镜头和场景，角色栏承载人物外貌与服装。
- 漫画与四格：包括导演、分镜、布局、文字归属和跨格连续性；新漫画默认先交完整文字分镜，已确认或明确要求直接转换时再按逐格框导出。
- 服装设计与衣物片段：可以只做设计、只交衣物串或只改指定部件；明确要完整画面时接回对应领域的字段规则。

用户已给定的剧情、服装、文字和逐字原串按其范围保留。完整导出按实际质量与 UC 预设去重和处理冲突；只复制文本不代表已经修改界面开关，也不会自动开始生图。

## 版本范围

本版已完成完整文字复核、混合任务应用回归与离线装配核验；本次没有新增 NovelAI 实图验证。既有示例、实图反馈及教程的证据边界在正文保留，不将有限应用当作生成成功率。

当前先提供完整整合稿，后续再据定稿拆分为单文件、通用构思＋写法和具体技能小包。此前的分包边界不作为本版新整合内容的固定边界。

公开仓保留的 `references/` 两份文件是 **v1.1 兼容目录**，不包含本 nightly 的漫画和服装整合内容，也不参与本入口的当前输出规则；旧版内容可查 [v1.1 参考目录](https://github.com/Miint-Sunny/nai5-prompting/tree/541d932bd5eec501700bd12ba4b74030dcab8009/references)。本次下载包只包含完整稿、SKILL、README、LICENSE 和 NOTICE，不附该旧目录。
