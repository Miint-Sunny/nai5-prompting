# NovelAI V5 构思与写法 · 极简版 · v1.2.6

本分支提供一个技能 `nai5-mini`：两份正文、全是平常话，只管**普通单幅插画**的构思和写法。主要维护形式是 [`main` 的拆分版](https://github.com/Miint-Sunny/nai5-prompting/tree/main)；极简版是独立维护的第二顺位形式，不从拆分版生成，漫画、OC 设计、服装和照图反推请用拆分版。

<a id="quick-start"></a>

## 配置与开始使用

本项目提供技能文档，配置只需放置完整技能目录，无需构建或安装项目依赖。

**未指定形式时，默认配置全部 11 个拆分技能。** 想要一个短的、只写普通插画的技能时，再选本分支的极简版。

推荐把[项目地址](https://github.com/Miint-Sunny/nai5-prompting)发给 agent，请它按照 [INSTALL.md](INSTALL.md)完成配置。明确选择极简版时，可发送：

```text
请按照项目中的 INSTALL.md，为当前 agent 配置极简版（nai5-mini）：
https://github.com/Miint-Sunny/nai5-prompting/tree/mini

保留完整技能目录，完成后告知配置位置和可用状态。
```

备用方式：下载[本形式的完整包](packs/v1.2.6/nai5-mini-v1.2.6.zip)，交给 agent 配置；或解压后，将完整 `nai5-mini` 文件夹复制到[客户端技能目录](INSTALL.md#manual-paths)。

## 版本与维护

当前为 **v1.2.6（2026-10-30）**，正式版，Latest；四个安装包和 Gemini 适配包都在 [v1.2.6 Release](https://github.com/Miint-Sunny/nai5-prompting/releases/tag/v1.2.6) 的附件里。相对 v1.2.5 改了（拆分版同步改）：两个人以上一定写方向前缀——一个人对另一个人做的动作，做的人写 `source#hug`、被做的人写同一个词 `target#hug`，互相做或一起做的写 `mutual#`（比如对视 `mutual#eye contact`），每张多人图至少一组；默认写在主串里各人那行 `Character N:`，用户说要把动作分开写进角色栏时，这几行的词连同前缀另起一行写进各人那一栏。角色栏照旧只放外貌和服装。依据是维护者的要求；官方说明里前缀写在角色栏，写在主串里不保证起作用；这一版没有出图验证。v1.2.5 相对 v1.2.4 改了（拆分版同步改）：栏名带冒号单独一行写在代码块上面，依次是 `Base Prompt:`、`Character 1:`、`Character 2:`……、用户要了才有的 `Undesired Content:`，代码块里只放要贴进那一栏的词；主串和角色栏每行末尾带英文逗号；两个人以上时主串前两行不写动作、姿势、表情和视线，主串最后空一行，每人一行 `Character N: girl, 动作, 表情, …,`，英文句子照旧一两句；一个人时不写这一行，动作、表情和视线直接写在主串第二行（原来接在角色栏最后的一两个动作词去掉了）；角色栏只放性别、外貌和服装，分两行（性别和长相一行、衣服和配饰一行）；给用户的附注放在最后的 `补充:` 下面；用户说要把动作分开写进角色栏时，主串不写那几行，动作、表情和视线另起一行写在各人那一栏最后。同日早些时候发布的 v1.2.5 第一版格式写得有歧义，已撤回。依据是维护者自己的用法和给的格式图；这一版没有出图验证，改动由模型评审核对。v1.2.4 相对 v1.2.3 改了（拆分版同步改）：不写质量词，图里要画字或用户要了质量词时，交稿最后提醒关掉官网的质量词开关；UC 用户要才给，没有自己的那套时用新的基础串（`2::extra characters, …` 开头那串，原来那串和官网 Heavy 预设相同）；两个人以上时主串前两行不写动作和姿势词，英文句子只写一两句谁在左谁在右、谁对谁做什么，角色栏不写动作（用户说要分开写才接在各人那一栏最后，互动带 `source#`、`target#`、`mutual#`），表情和视线照旧写在各人那一栏，`Character 1` 是最左边那个；人物长相用户没给就不写、不编，句子里可以用衣服叫人；要大片留白、整页空白或主要画 logo 时提醒换 UC 预设。依据是使用反馈和 NovelAI 官方文档；这一版没有出图验证，改动由模型评审分两轮核对。v1.2.3 相对 v1.2.2 改了：按补测结果修订一组需求还原规则（闭眼时题目或设定里有眼睛颜色也不写；两人并排走明说用 three-quarter view、不用 from side；几个人时 blowing 也写进吹气那人那一栏；画法改成单独一行写在句子的下一行；字那条只留那一面朝着镜头，撤掉「放平」和「不俯仰拍」），随便画加一条定完只看画面再看一遍、看不出就换一样开头的东西重想，嘴里有东西又说了表情时挑做得出的嘴的词，另把角色栏各词的先后、英文句子的顺序、机位各最多一个等几处会读成两种做法的说法写清。依据：v1.2.2 里没单独测过的五条和两处没说清的写法，各做了只差一处、4 个种子的真出图对照：闭眼不写眼睛颜色、两人并排走从斜前方拍稳定、大幅更好，近景不配 standing 小幅更好，姿势词不打架、几个人时 blowing 进角色栏看不出差别，字不俯仰拍、画法写进第一行没有更好，撤回；随便画那条和嘴里有东西那条没有单独出图验证；全文另由模型评审逐句改清说法；这一版没有再做整版同题对照。v1.2.2 相对 v1.2.1 改了一组需求还原规则（人在走、坐在地上用全身景别，同一个人的姿势词不打架，近景不配 standing，两人并排走从斜前方拍；题目要的数量、画法写成前两行的短词；字那一面正对镜头、不俯仰拍，没原文就写一句短的；只说季节打扮时季节不进场景；动作停在正在做的那一下；呵气写 pursed lips 加 blowing；闭眼也不写眼睛颜色，吃着东西也不写嘴的词；删掉模板第一行的门框、窗框和「第一行的东西」那条的物件例子，时间格改成时段）加三处文字一致性（旧句对齐嘴词规则；没有脸的不写表情；自检只查有脸且嘴没在忙的人），版权角色长相的写法和「表情写一个嘴的词」这条不变。单变量对照（其中五条规则各自两版词只差一处、4 个种子）：走和坐在地上用全身景别 9 次评比全赢（11.00 对 9.11），脸没有因为人变小而变差；冬天的季节词写进场景会多出题目没要的雪，只写在衣服上雪就少了（一题明显、一题小幅，都稳定；夏天写不写一样）；呵气写 pursed lips 只在一题小幅稳定更好；动作停在正在做、数量写进前两行看不出稳定差别；字正对镜头、姿势词不打架、近景不配 standing、并排走从斜前方拍、闭眼不写眼睛颜色没有单独对照。整版对 v1.2.1 同题对照，双方都重新写词，共出图 极简版 2026-10-17 从零起草：先定标准（必须做到的事、写法上的硬要求、测过的坑），三路独立起草、三个模型评审、合成、挑错、修订，再按盲评点名的缺口补了四句。对照测试用 16 道二次元题、DeepSeek Flash 写词、16 题 × 3 位评委盲评（满分 50）：拆分版 36.45，极简版 37.33；极简版的语法字段与简洁最高，需求还原最低，写一份的输出 token 约为拆分版的一半。v1.2g 只验证了文字；v1.2 的三条规则各做了只差一处、4 个种子的真出图对照，再整版同题出图核过不退步；v1.2.1 的表情规则做的是对 v1.2 的整版同题出图对照，另外两版落选候选也各和它比过一轮；v1.2.2 的需求还原规则里五条各做了只差一处、4 个种子的真出图对照，再对 v1.2.1 整版同题出图核过打平，记录见发布说明。
