# 技能包下载

推荐将[项目地址](https://github.com/Miint-Sunny/nai5-prompting)发给 agent，请它按照[配置指南](../INSTALL.md)完成配置。此目录提供手动下载的备用方式；技能文件无需构建或安装项目依赖。

## 当前版本：v1.2e

用户未指定形式时，配置完整拆分版；使用时优先从拆分技能中按需读取。合并版和单文件版仅在用户明确指定时选择。

| 文件 | 内容 |
| --- | --- |
| **[nai5-split-v1.2e.zip](v1.2e/nai5-split-v1.2e.zip)** | 全部 11 个拆分技能，默认选择 |
| [nai5-merged-v1.2e.zip](v1.2e/nai5-merged-v1.2e.zip) | 一个入口与构思、写法两卷 |
| [nai5-single-v1.2e.zip](v1.2e/nai5-single-v1.2e.zip) | 一个入口与完整合订稿 |

下载后可将 ZIP 交给 agent 配置，或解压后按[手动配置目录](../INSTALL.md#manual-paths)放置。仅支持逐个导入的客户端，可使用 `v1.2e/individual/` 中的 11 个小包；完整职责和下载清单见[主线说明](https://github.com/Miint-Sunny/nai5-prompting#split-skills)。

`packs/` 用于存放分发文件，`v1.2e/` 是其下的版本目录。当前仓库仅保留当前版本的包，历史版本从 [Releases](https://github.com/Miint-Sunny/nai5-prompting/releases) 获取。
