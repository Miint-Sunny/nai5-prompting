# 漫画身份与状态连续性

连续性记录故事中的事实、当前状态和镜头所见。不需要把整份状态表贴给用户，也不把所有画外设定塞进每格。

<a id="comic-continuity.s01"></a>

### 建立够用的连续性记录

| 层 | 记录什么 | 落实到分镜时 |
|---|---|---|
| 身份 | 发型/原色及本次显示颜色或明暗、体型、种族特征、辨识配饰 | 只取实际可见项；不能为省词随意改身份 |
| 本场服装 | 轮廓、领口、袖长、层次、下摆、原色及本次显示颜色或明暗 | 同一可见部件复用相同描述；被裁切/遮住的部分不写 |
| 道具结构 | 数量、轮廓、开合方式、提手/附件等剧情必需项 | 同一道具复用短小固定称呼和结构，不能后文换一种机构 |
| 状态 | 开/关、覆盖高度、归属、所在位置、手的接触、内容物是否可见 | 逐格更新；变化由动作或可理解的格间省略支撑 |
| 空间 | 必要地标、人物相对位置、视线与运动方向 | 换机位仍能理解空间，不要求每格重画全套布景 |

用户已指定的服装、饰品、道具结构、台词先完整记录，不能以“与剧情无关”为由删除。未指定部分只记录对故事或辨识有影响的细节，不为一个背景杯子编型号。

- **用户要求本格可见**：将该细节作为镜头条件保留；既定镜头确实装不下时明确指出冲突，不静默裁掉或替换。
- **事实仍在但本格画外**：留在连续性记录，当前分镜描述省略；再次入镜时按原事实恢复。裁切不改角色、服装或持物事实。
- **未指定部分**：按剧情需要简洁补足，不擅加身份特征或复杂配饰。

用户只改某一处或冻结原文时，除目标改动外保留原来的文字、空格与标点；颜色和连续性检查不能成为无关改写的理由。复杂段落可用“页号及画格位置/大小／可见范围／固定锚点／当前状态／承接动作”快速核对。

<a id="comic-continuity.s01.h01"></a>

#### 同页逐格的持续状态

每格写本次新动作，也写先前已成立且在当前镜头中仍可见的状态。分镜不能只记录变化，让上一格的持物、接触或位置凭空消失。

- 按故事先后区分“尚未发生、正在进行、已经保持”的状态。多个部位或物件依次操作时，各自保留当前阶段，不把后一步的结果提前混进前格，也不把前一步重置。
- 例如右手已拿起钥匙，接着左手拿杯子：两手入镜时同时写右手仍持钥匙、左手拿杯子。改为脸部特写时省略画外的手与物；以后重新入镜，再按当时状态写明。裁切只改变描述范围，不改变故事事实。
- 需要交代空缺时，直接写简短状态，如“空着的左手”；不列举这只手没有拿哪些物品，也不为避免未来物件提前出现而逐项点名排除。只写与本格有关的当前状态。



从实图借鉴连续性时，分开检查信息顺序、空间关系与可见状态：对白接得上不等于左右手、物件或距离都已连续。局部细节后拉远可重新交代关系；旁白可以压缩无须展示的时间，但不能替代读者必须看清的状态变化。段落连接可参考 [漫画导演的节拍与连接](comic-story.md#comic-director.s05)；更换镜头不会重置已经成立的状态。

<a id="comic-continuity.s02"></a>

### 契诃夫之枪：先建立功能，再让它生效

- 后面要拉拉链，前面出现的包就要是拉链包；后来需要纸条，就应有合理出现或发现的过程。
- 一个被特意强调的结构、道具或声音，应承担动作、线索、人物塑造、气氛或节奏作用。只增加绘制负担却没有作用的强调细节，删掉。
- 这不是“所有背景与角色饰品都必须推动情节”。必要环境与身份锚点可以保留；故事开头的伏笔允许在后文兑现，不能为了立刻回收而把开头写成结局。
- 剧情依赖物件功能时，先定它如何被操作，再补相应外观：要从口袋取物，就交代口袋所在一侧和手能到达的位置。仅作装饰的标签或吊坠可以保持背景程度，无需另编事件。
- 道具辨识优先复用已确定的轮廓、开合方式和关键线索；发生漂移时，先检查这些描述是否一致。新增补丁、刺绣或吊牌只在本次设计确有需要时加入，避免增加逐格保持的负担。

**包的修正示例（不是所有包的默认设计）：**

例如固定为“小型长方形布包，两条短提手，顶部一条拉链”。第一次包口可见时建立顶端拉链；若后文操作拉片，先确定单个滑块及所处端。按动作顺序写“拉链闭合→手握拉片拉开一段→开口露出内容物”。可见的固定结构在相关格重复，状态不同就改状态，不改包型、提手或开合机制。

如果故事无需拉链，用敞口包即可；如果已经明确是按扣包，就延续按扣的开启动作。不能给按扣包临时装上拉链。吊在提手上的纸签也不能无故变成缝在包内的标签。

先核对原稿，区分“前后描述不一致”“遗漏关键结构”和“描述一致但模型漂移”。用户给的实图是结果证据，不等于对应的底稿；区分底稿矛盾与实际表现偏差。

<a id="comic-continuity.s04"></a>

### 换装和覆盖物需要状态连续

用户要求简单日常服时，先确定本题人物的服装基底，再分镜。优先少层次、易辨轮廓和不同明暗；领口、袖长、裤/裙轮廓等固定下来。确需新设计时可接 `oc-costume-design`，带回已定服装继续本次分镜；已有服装直接沿用，只改服装时交替换描述，不额外重审故事。用户要转换提示词时另接 `nai5-writing`。

不要把一次换装写回 OC 的永久设定，也不要把“所有漫画必须穿短袖”变成规则。

**手部校验：** 短袖上衣的袖口在上臂；手和前臂特写若没有拍到上臂，就只写裸露前臂，不继承旧星纹长袖或西装袖口。

**毯子校验：** 从颈下近景切到双人远景，覆盖边沿仍须落在同一身体锚点，例如颈铃下方/上胸。若要降低到腰部，先安排放下毯子、坐起或另一人拉动等能解释变化的动作；换景别本身不是毯子滑落的原因。盖住的衣服留在事实记录里，当前分镜只描述实际可见部位，避免把显示衣服与保持覆盖同时当作取景要求。

写清“当前看得见什么”，不把未来动作后的状态提前混进同一格。物件数量、谁拿着它、哪只手接触和位置同样如此；已成立的状态在后格仍入镜时继续写明，不能只写本格的新动作。

<a id="comic-continuity.s05"></a>

### 场景连续与镜头选择

同一房间反复出现时，必要地标、站位和物件状态应连续。根据阅读目的决定何时需要重建空间：

- 引出情境、渲染气氛或重要结果的大格，给够建立空间所需背景。
- 反应、手部、道具等小格尽量省背景，必要时留一个桌沿/门边等空间锚点，不重复整套房间。
- 跨页用合适的近景、反打、局部取景和视线连接，避免为了交代相同信息再画同机位全景。
- 若剧情依赖前后对照，或转场确实需要重新定位，则保留必要全景；不要为了遮掩漂移破坏读者理解。
- 换角度不能掩盖事实矛盾：开合、覆盖高度、衣服结构和道具数量仍要对得上。

镜头变化服务读者理解，不为掩盖生成差异而改掉既定镜头。没有修改后的实际图时，只能确认稿件内部一致。

## 色彩表现与身份事实分开

新漫画未指定模式时默认全彩；续页和局部改稿延续本次已定模式，用户本次切换优先。黑白、半黑白或局部保色是表现选择，不改变人物、服装和道具的原色事实。保留原色记录，同时确定画面上需要连续的明暗关系、对比和保色范围；浅发与深衣不能因为换页就颠倒。

默认半黑白仅头发与眼睛保色，其他部分灰阶；用户明确另外的范围时按本题范围。黑白保留轮廓、材质与明暗，不等于删除部件。具体如何转成词句与检查全部字段由 `nai5-writing` 处理，本阶段不生成风格串或排除词。
