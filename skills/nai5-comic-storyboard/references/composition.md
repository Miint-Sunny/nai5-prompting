# 想法转插画构图

把已有想法变成一幅具体画面：选择怎样看、看见什么、各部分怎样一起表达。用户已定的主题、角色、服饰、文字、镜头或部件先保留；未定部分围绕画面意图发挥。先让方案说清画面里最值得看的内容在哪里，其他部分怎样围绕它摆放。

用户若只要改视角、人物距离或一个动作，直接处理该处及必要的空间关系，不从头改主题。整体想法尚未定时可以先给本次所需的构图主案；明确要探索主题则交 `nai5-ideas`。形成画面方案就是本阶段的完整结果，不默认继续转词。

<a id="ideation-composition.view"></a>

## 镜头、空间与主次

先问第一眼应看见什么，余下内容怎样引导或衬托它。景别、相机高度、观看方向、裁切、遮挡、透视、主体占幅和前中后景可以一起调整；不是每次都要用同一种戏剧机位。

要强调高度，可把机位放低，让近处结构从画边向上延伸；要看桌面分工，可从斜上方同时看清物件与各人的手；要从隐蔽处观察，可让门边或近处物件遮住部分视野，人物留在后方开口里。近景可只露局部，中景承担主动作，远处人物可以缩小；等大、同平面、正面全身也可以是用户要的展示形式，不能当作必须纠正的错误。

写实空间中的尺度、接触和遮挡应能彼此解释；梦境、拼贴、象征或故意扭曲透视则按其表现逻辑组织，不用现实几何否决创意。用户要求某细节可见时将它作为取景条件，镜头确实装不下就指出具体冲突，不能静默裁掉。

<a id="ideation-composition.action"></a>

## 选择瞬间与人物关系

根据意图决定正在发生什么，或为什么值得停留。递物停在手刚伸到的瞬间、想接又收回的手、另一个人故意看向别处，都比泛泛的“互动”具体。安静站立、睡着、空镜或纯展示同样成立，不强制每个人都在运动或与环境互动。

多人时可考虑谁发起、谁接受、谁旁观、谁根本不参与；这些是创作选择，不是人人必须填满的角色格子。一个人置身事外有时更衬出其他人的关系。动作包含接触或共用道具时，从当前动作确定谁握哪一部分、另一只手在哪里、物件由谁承托、身体靠什么支撑；局部镜头仍说明各只手从哪侧进入。

表情、视线、身体张力和道具状态相互支持。需要一个冻结瞬间时，不把拿起、转身、跑走全塞进同一身体；需要多时刻拼贴时把表现意图说明白。没有“必须几个动作、几个表情”的配额。

<a id="ideation-composition.light"></a>

## 光色、材质与气氛

可以从光色灵感先开始，再寻找能承载它的人物和空间。主光方向与性质、反射或第二光源、冷暖、明暗对比、材质和边缘，共同决定画面情绪；不需要把这些全写成参数表。

写实逆光先交代光源相对人物的位置，再确定哪些边缘受光、正面有没有补光及补光来自哪里；没有补光的暗面保留其明暗区别。用影子提示画外对象时，明确影子进入画面的方向和承接面；环境为重点时，给空间延伸留出面积。舞台光、梦境色或平面色块按各自形式安排，不必模拟同一种自然光。

<a id="general-ideation.s07.h01"></a>

## 按需要回看画面关系

从意图与场合、人物、动作、场景、取景和光色中，选择本次尚未清楚的部分继续展开。人数或站位变化时检查受影响的空间与动作；已有关系成立就保留，不因回看而重做全部构图。

交付前看应当可见的信息是否进了镜头、动作和视线是否表达意图、光色与空间是否符合选定表现逻辑。它们是可往返的观察角度，详略由当前问题决定。

<a id="ideation-composition.variants"></a>

## 变化来自表达，而非凑元素

想比较构图时，可改变观看距离、遮挡、人物与环境的主次、动作瞬间、场合或调子。贴纸、设定展示、留白、分格和画中实物也都是构图方向，只有任务需要才选。方案的数量和变化幅度由当前目标决定。

比较方案时说明改变了哪种观看体验：靠近后能看清哪些反应，拉远后哪些环境关系成为重点，换一个瞬间会让动作表达什么。场所、姿势与光色从当前主题发展，不从教学例子中整套取用；用户明确要沿用某一构图时，保留其指定部分。

<a id="ideation-composition.series"></a>

## 分格展示中的视觉联系

表情集合、衣装展示或设定页不必都变成故事漫画。展示衣装时，可放一张较大的全身图交代轮廓，旁边小图分别放背面开合、袖口或鞋型；表情集合可保持同一脸部尺度，方便直接比较。共同色条、对齐边缘或重复的底色能把视图连在一起，也可以仅靠大小和间距分组。

把版式做成画中实物也是一种选择：侦探线索板、相册页、摊开的拍立得，让多个小画面有共同载体；同样可以用纯平面排版。若有标题，先留出文字区；字在人物后方时说明被哪些轮廓挡住，字在前方时避开需要读清的脸、手和细节。若要连贯叙事，接 `nai5-comic-storyboard` 安排时间与阅读顺序，不把静态多视图自动解释为多个时刻。

<a id="ideation-composition.deliver"></a>

## 交付画面方案

用自然语言交代最值得保留的瞬间、构图、人物与空间关系、必要光色和细节；详略随请求，不必须填完长表。不补提示词字段、不挑标签或处理排除词。用户要继续转成 NAI 提示词时，带现有方案与锁定内容交给 `nai5-writing`；已有方案直接接，不再询问一遍已确认事项。
