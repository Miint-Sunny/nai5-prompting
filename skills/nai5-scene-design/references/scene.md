# 场景与情境构思

从一个地方怎样存在、怎样被使用，以及它让人产生什么感受出发。场景可以是故事发生的条件，也可以独立成为观看主体：空旷的盐田、正在苏醒的车站、始终无人经过的连廊，都值得作为完整作品。用户已经给出的地点、时代、天气、物件、人物与可见细节先保留，从尚未决定的环境关系展开。

只要场景点子就交具体情境；要环境设计才深入空间、运行与材料；已有场景要构图则围绕当下观看关系落实。以下方法按问题选用，例子是原创假设，不是用户设定或固定素材池。

<a id="ideation-scene.subject"></a>

## 让环境承担画面的吸引力

先抓住这个地方最值得看的一种关系：庞大的结构与细小的使用痕迹、平稳秩序中的局部变化、明亮表面下的幽暗通道、看似相同却逐渐偏离的重复。要看巨大结构，就留出从近处基座到远处顶端的轮廓，人物可小到只作尺度参照；要看使用痕迹，就靠近扶手、门槛或台面，让磨损位置可辨。人物需要交代使用方式时再入画，例如弯腰穿过矮门。

环境成为主体不等于只能画大远景。反复修补的门槛、夜里仍温热的石墙或柜台上被磨亮的边缘，都可以借局部让人想见整个地方。远景适合展现地形和结构的呼应，局部适合触觉与时间，中间尺度能看清怎样进入、停留和使用。

例如，构思“退潮后短暂开放的市场”，吸引力可以是摊位沿露出的石脊铺开，水沟保留刚才海面的亮光，较高的平台已经开始收摊。这里的地点、时间和使用方式相互解释；不必再塞入一个戏剧人物，环境本身已有变化。

<a id="ideation-scene.life"></a>

## 从生活与运行方式长出空间

想象这里平常如何运转：人或其他使用者从哪里进入，东西如何运送，何处工作、休息、交换、储存，什么需要照料，哪里会被反复触碰。挑与当前场景有关的过程，把它变成路径、开口、设施和摆放关系。物件由用途找到位置，空间就不只是装饰的集合。

同样一间修理铺，面向街坊的日常服务可能让门口宽敞、常用工具伸手可及，等候处能看见工作；专为高塔维护的工坊则可能围绕升降与悬挂组织。前者可把工具架放在工作台后、等候凳放在门边，留出顾客与工作区之间的通道；后者可让工作平台围绕竖井分层，吊索穿过各层。新建、洁净、被精心维护的地方也有生活痕迹，不必靠破败和杂乱证明真实。

幻想场景可以从自定规则推演：若物件会向光缓慢漂移，储存、遮阳和交通会怎样适应？可以把储物架移到背光墙、给开口加遮光帘，或让收货处朝向光源，物件自己缓慢靠近；选择与当前画面有关的后果展开。非叙事或纯形式的环境也可依靠重复、重力方向、材料变化等视觉关系成立，无需补全社会制度。

<a id="ideation-scene.space"></a>

## 建立可感知的空间关系

用边界、通路、层次与遮挡让地方有结构。入口通往什么，何处收窄或展开，视线在哪里被截住又重新打开，附近与远处怎样呼应？需要让人理解路线时，让入口、转角和远处目的地至少有可辨的连接，例如地面亮带转过柱脚后通向楼梯；需要迷失感时，可让相似门洞重复到远处，并用近墙遮住岔路的一端。

尺度靠关系显现：扶手与手、楼梯与步幅、树根与建筑、风化纹理与远方轮廓。可以保留现实尺度，也可以有意拉长、压扁或错置；判断依据是本题的表现逻辑。用户明确要看见的细节应进入方案，必要时调整观看位置与主次，而不是先把它们当成可删的杂物。

场景还包含画外：通道继续到哪里，声音从什么方向来，窗外的光意味着什么。画外空间能扩大想象，不需要把每个去处都解释或画出来。局部修改一座桥或一个入口时，检查相连路径与使用关系即可，保留其他已经成立的空间。

<a id="ideation-scene.time"></a>

## 用时间与天气改变同一个地方

选择正在发生的时段和变化，而不只贴“清晨”“下雨”的标签。早班开始前，哪些地方先亮起来、哪些仍关闭？雨刚停时，什么先干、什么还积水？风会带动柔软物、暴露朝向差异，也可能让原本热闹的路径暂时空下来。

痕迹应来自原因：搬运留下的磨损落在常走的边缘，褪色跟随受光面，反复开合改变接触处，临时搭建留下与长期结构不同的连接。洁净与未被使用也能表达刚刚建成、被保护或等待启用。选择能形成当前感受的痕迹，无需为所有表面编年史。

叙事情境可让痕迹提示刚发生的事或将发生的变化；静观环境则可以停在循环本身，如光斑缓慢移过空座椅。并非每一处痕迹都要成为谜题、危险或待回收的伏笔。

<a id="ideation-scene.material"></a>

## 让尺度、材质和气氛相互作用

材质不只是物品名称：厚石墙的窄缝可以只照亮内侧一道边，湿木板把灯光拉成长反光、旁边干布仍保持柔暗，薄金属片则用翘起的边缘和松动挂点显出轻薄。把表面、厚薄、边缘、透光和使用状态连到空间体验，选择与本题有关的表现。

气氛可来自彼此配合或抵触的关系。温暖小灯被巨大冷空间包围时，灯下放近座椅、杯子和可进入的小门，可以使亮处像可停留的住处；把灯留在远处高窗、前面隔着无路穿过的空场，会增加距离感。同一冷暖配色，通过入口、生活物件和距离就能形成不同情境。

色彩可以服从自然光，也可以组织平面色块、季节感或象征。明亮、整齐、普通的环境同样能有个性；幻想材料和异常尺度可以大胆使用，只需让它们在当前作品中有可感受的联系。

<a id="ideation-scene.deliver"></a>

## 交出本次需要的地方

把场景写成能被想见的方案：它是什么样的地方，最有吸引力的关系是什么，空间或生活如何支撑这种关系，以及本次时刻有什么值得看。只要一个氛围点子时可以很短；环境设计需要时再展开区域、运行、材料与变化，已有答案不重复填表。

环境要进入插画时，可接 `nai5-illustration-composition` 选择具体观看方式；要在漫画中反复出现，可接 `nai5-comic-storyboard` 安排地标、揭示与连续性。用户直接给出完整画面并要转词时，带现稿交 `nai5-writing`。场景方案本身也是完整结果，接续只发生在当前请求需要的地方。
