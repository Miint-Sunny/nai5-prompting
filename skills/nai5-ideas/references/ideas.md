# 整体想法构思

先想值得展开的内容：想表达什么、谁处于什么处境、什么关系或变化让人记住。想法可以从人物、情绪、世界规则、矛盾、声音、物件、梦境或形式实验出发，不必一开始就适合某张画、某种模型或现成词库。

用户要一个点子就给一个扎实点子，要比较方向才展开所需选择。整体构思可以停在主题、故事种子、角色关系或梗概；不默认附镜头表、提示词或下一阶段确认表。

<a id="ideation-ideas.scope"></a>

## 从还没决定的地方开始

已有主题就沿它发展，已有故事就只处理未定关系或走向，明确只想找现成图片则如实按检索任务处理；没有检索能力时说明，不能把新构思冒充找到的图片。已给出完整画面而只要转词时交给 `nai5-writing`，不重新创作。想法已成立而要变成单幅构图，可接 `nai5-illustration-composition`；要安排漫画可接 `nai5-comic-storyboard`，这些都不是必须依次经过的步骤。

资料不足不等于不能想。能给具体主案时先给，把新增设定说成建议；只有缺口真正妨碍当前任务、涉及用户锁定事实时才问。不要用一轮泛泛提问替代创造，也不要在身份不明时编造用户的角色设定。

用户明确的角色、剧情、服饰、镜头、文字与改动范围先保留；原句、空格、标点和其他冻结文字不因润色而改。未指定部分可以充分发挥，幻想、荒诞、静观、留白或非叙事表达都可以成立。只改一个想法的落点时保留其余已认可内容。

<a id="ideation-ideas.explore"></a>

## 找到有记忆点的核心

可以顺着当前兴趣试探这些方向，而不是逐项填表：

- **关系和反差**：谁依赖谁、误会了什么、习惯在什么场合失效？熟悉的人或物进入不相称的环境会发生什么？
- **欲望和代价**：想得到什么、为什么不直接拿到、做出的选择透露什么？抒情或日常小品不必硬加危机。
- **规则和例外**：把世界里的一个常识改变后，生活会怎样？保留可理解的后果，让奇想有自己的逻辑。
- **感官和情绪**：从温度、声音、材质、空旷、压迫或亲近感出发，找能承载它的情境，而不是先罗列装饰。
- **物件和母题**：一件物如何改变关系，重复出现时意义怎样变化？物件也可以只是审美重点，无需都变成机关。
- **形式和视角**：把一个事件交给不常见的观察者，用书信、物件痕迹、相册、梦或并列日常来组织。形式服务体验，不为求新强加复杂结构。

熟悉的表达可以很好，陌生方向也可以探索。“空地”只是本次尚未尝试的方向，不是必须凑出的稀有方案。不要先排除固定数量的常见构图，也不要靠堆花瓣、星星、粒子或漂浮物假装概念充实；这些元素有表达作用时仍可使用。

<a id="ideation-ideas.character"></a>

## 角色事实与创作自由

版权角色不熟悉且确有查询能力时，核对相关档案和可靠参考：外貌结构、性格与职能、故事背景、已有服装和文化语境。资料是帮助理解角色的材料，不是把所有已知信息都塞进方案的要求。查询不到时保留用户事实，不把模糊记忆写成已核实设定；不确定内容可以作为有意的创作建议。

查档案不等于只能照原设定。反差、AU、换装、玩梗和有意 OOC 都可以是明确的创作选择；要知道自己偏离了什么，区分有意改变与无意认错。角色是否被模型收录、规范标签拼法和激活强度属于写法问题，不限制想象。

使用已有原创角色时，以用户提供或实际启用的资料为事实，在本次开放范围内发挥，不臆造私有条目。用户明确要求从零设计 OC 时，可以大胆提出身份、性格、外貌和关系方案，并将新增内容作为本次设计提案；没有 OC 库不妨碍创作。角色名字、既有形象和本次可以改变的部分分清，一次提案不自动写回永久设定。

<a id="ideation-ideas.topics"></a>

## 按本次题材选读

需要深入某个方面时再选相应专题：完整稿按下列同名专题章节选读，独立包则按已启用的技能接续。未启用其他技能时，用当前包的方法完成能做的请求，如实说明边界，不声称读过缺失资源。专题可以组合，也可以停在当前想法，不是必须全部经过的分类流程。

- 场景与情境（可选技能 `nai5-scene-design`）：让环境成为主体，发展空间的生活、运行、时间与气氛。
- 情绪、象征与艺术表达（可选技能 `nai5-art-direction`）：探索感受怎样通过画面关系、象征、节奏和形式成立，也可按需分析参考风格。
- OC 整体角色设计（可选技能 `oc-character-design`）：从零发展角色核心、世界关系、行为与外形，或修改已有角色的开放部分。

漫画架构、页格与分镜沿用 `nai5-comic-storyboard`；具体服装设计沿用 `oc-costume-design`。例如环境主导的漫画可以在需要建立场景时读场景专题，已有 OC 的换装则直接处理服装，不重新设计人物。用户给定的具体细节与冻结原文随当前方案保留，未选专题不默认加载。

成人向是可能与各题材交叉的内容范围，不等于一种画风或媒介；非露骨与露骨范围按当前明确要求区分。本导航仅作中性分类说明，不提供露骨内容的创作方法、示例或生成技巧。

<a id="ideation-ideas.compare"></a>

## 让不同方向有真实区别

比较方案时看体验或核心关系是否变化：同一事件换成另一人的视角、从冲突转为日常观察、让环境而非人物主导、把直接揭晓改成余韵，都会带来有意义的变化。用户要配色变体时，只变颜色也可以是完整目标，不强制每案改变多个维度。

需要解释时简短说出方案的吸引力、保留的用户要求和仍开放的部分。不要复述内部流程，也不预设必须给出基线、探索案或取向说明的数量。首答交实际想法，不只列接下来准备想什么。

<a id="ideation-ideas.handoff"></a>

## 交付与接续

交出本次需要的主题、梗概或故事种子；可以指出一个值得继续展开的问题，不强迫把它全部解决。接下一阶段时带着现有文字与用户已经确定的内容即可，不要求重新填写一份交接模板。构思到此可以独立完成。
