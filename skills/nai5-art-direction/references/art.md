# 情绪、象征与艺术表达

具象、写实与风格化画面都适用这里的情绪、象征、构图光色及媒介画风探索；抽象与超现实只是可选方式，不默认把用户的具体场景抽象化。

从想让观者感受到什么、怎样观看和联想出发，探索画面的形式；画风与媒介选择服务这种体验，也可以成为探索的起点。用户已经确定的主题、人物、服装、物件、文字和镜头继续保留，在开放部分发展表达。下文的例子是原创假设，用于说明选择怎样产生不同感受。

只要表达方向就交有画面内容的提案；需要风格分析才展开参考的视觉做法；已有方案只调一处形式关系时，保留其他已认可决定。构思阶段谈感受、形状、笔触和观看体验，不把它们提前变成标签配方。

<a id="ideation-art.feeling"></a>

## 把感受发展成观看关系

情绪可以有方向、强弱和转折：是想靠近却有所保留，已经结束却还不愿离开，还是安静地被某种庞大事物包围？可以用接近的身体与回避的视线表现保留，用已收起的物件与仍停在门口的人表现不愿离开；表情再配合这些位置和动作。

距离、遮挡、触碰、视线、物件位置与空缺都能承担感受。例如“仍为离开的人留着位置”，可以让餐桌其他位置都被日常杂物占据，唯独那一处整洁；也可以只画对面椅背上的余光，让缺席没有明确解释。前者更易读出日常关系，后者更含蓄，选择取决于希望观者停留在哪里。

也可以从愉悦、丰盛、平稳或纯感官兴趣开始，不必先制造痛苦和矛盾。色彩间轻快的呼应、缓慢展开的形状或触感相近的表面，都能支撑没有故事结局的作品。

<a id="ideation-art.metaphor"></a>

## 让象征在画面里发生关系

先理解本题中一个物件或形象为什么承载意义：它和人物的经历、动作、场所或反复出现的方式有什么联系？然后决定通过尺度、位置、变化、缺失或组合，让这种意义可被感受到。象征不等于给抽象概念配一个通用图标；同一物件在不同关系中可以产生相反含义。

例如“无法寄出的道歉”可以让信封越来越厚，桌面逐渐没有可写的位置；也可以让一张薄纸占据很大的空白，字迹只停在开头。前一种让信封挤占桌面、压住未写完的纸，后一种让短短开头落在大片空纸上；观者分别看到积累的负担与停笔后的空缺。用户已经指定某种象征物时，优先把它组织好，而非换成更常见的符号。

隐喻可以容易读懂，也可以保留歧义。要让观者理解因果，就建立必要的前后或接触关系；要留下余味，就让意义有可探索的线索，不把画面说明写成唯一标准答案。采用有文化背景的符号时，区分已知含义、参考给出的依据和自己本次赋予的意义。

<a id="ideation-art.rhythm"></a>

## 用节奏、密度和留白安排体验

关注眼睛怎样进入、停留、离开或回看：密集区域会怎样衬出空处，重复形状在哪里发生变化，硬边在哪里变软，色块之间有没有呼应。节奏不只来自斜线和动作，等距排列、微小差异和长时间的静止也能建立观看秩序。

留白可以形成等待、距离、轻盈或压迫，取决于它和主体的关系。一个物件靠近边缘时，空处可能像未到达的地方；被密集纹理围住的小空处则可能像呼吸。要表现尚未到达的距离，可把主体放在一端，在它面向的方向留出连续空处；要使小空处像喘息的位置，可让周围纹理密集、靠近空处时逐渐稀疏。面积随这段距离或密度变化调整。

若要加强表达，先改变最相关的关系。例如把重复的间距逐渐拉开，可能比再添加一个象征物更清楚。用户指定必须出现的细节，通过层级、疏密和位置协调；它们不因“做减法”自动失去保留资格。

<a id="ideation-art.unreal"></a>

## 抽象与超现实各自怎样成立

抽象可以从真实经验中提取关系：水面波动留下的节奏、拥挤与疏散的密度、记忆由清楚变模糊的边缘。选择想保留的运动、形状或色彩联系，让它们成为画面内容；不必最后又加一个写实人物来解释主题。

超现实可以改变尺度、材料、空间或时间之间的关系。先选择本题有意味的变化，再想其可见后果：若一间屋子随着记忆被折叠，可以让墙角形成折线，桌面与门框沿同一折线弯转，窗光也在折面上转向。变化可以局部而含蓄，也可以使整个世界遵循另一种逻辑。保留足够的感知线索，让观者知道异常发生在哪里，而不要求幻想符合现实工程。

梦境、拼贴和象征层可以并置不同时间或视点。决定哪些部分属于同一现实、哪些是联想或叠置，表达才有自己的方向；不必为了消除所有矛盾而把它们整理回普通场景。用户要的荒诞本身也可以成为目标。

<a id="ideation-art.form"></a>

## 选择媒介、形状与笔触的作用

先问需要怎样的表面和边缘，再选择表达语言。连续细线可以追踪犹疑的动作；大片平涂可让深色块贴近浅色人物轮廓，压缩它周围的空处；柔软渗化可以让边界消退；粗粝痕迹可以保留摩擦与速度。这些是可尝试的作用关系，不是某种媒介必然对应某种情绪。

形状也有自己的组织：圆润与尖锐如何相邻，完整轮廓在哪里断开，人物与背景采用同一种形状语言还是刻意分离？材质与笔触可以统一全画面，也可以只在关键区域变化，让观者从流畅处停在异常处。已锁定的外形与服饰结构仍应能辨认，风格化的幅度按用户要求掌握。

选择水彩感、版画感、拼贴、素描或数字绘画等方向时，具体说明需要的是透叠、压印边缘、纸片搭接、线条密度还是其他可见做法。这样即使媒介名称相同，方案也有区别；即使不用媒介名称，表达意图仍然清楚。

<a id="ideation-art.reference"></a>

## 从参考中分清题材与表达

有参考图时，先描述真正看见的组织方式：主要明暗块各占哪里，冷暖色相邻还是隔开，轮廓何处清楚何处消失，笔触相对人物有多大，远近景是否压在同一平面，以及细节集中在哪些部位。再判断哪些做法可能促成当前感受，区分可见观察与个人解释。没有实际读到的参考，不声称已分析其风格。

此处分析用户实际提供或指定的参考。普通创作不因追求某种个人取向就自行搜索其旧作品或反推；已有整理后偏好可直接使用。核对偏好依据与整理参考另按用户明确要求进行。

对照参考时，分清用户要借用的是光色与媒介、常用形式，还是这张图的具体构图。即使更换角色与道具，保留同一组姿势、空间分层和物件作用，也可能仍是原图变体。独立新图从当前内容重新组织这些关系；用户明确要沿用指定构图时保留其指定部分。

组合参考时让各自有作用：一个帮助理解光色，另一个帮助研究线条或空间，最后检查它们在本题中能否共存。需要时说明来自哪张已提供参考，避免把自己的新增判断说成原作者意图。具体模型是否识别风格名、如何写画师串，留给写法阶段处理。

<a id="ideation-art.deliver"></a>

## 交付能够被想见的表达方案

交出实际画面关系与感受之间的联系：什么内容承担表达，准备怎样组织形状、空间、色彩、密度或笔触，观者会先注意什么、随后可能联想到什么。只要一个方向就认真发展它；用户要比较时，让方案改变可见安排，例如一案让两人靠近却看向不同方向，另一案把两人隔远但让视线相遇；简短说明各自形成的感受。

给出方案不等于解释尽所有意义。用户只要画面时让画面成立，需要说明时再简短解释选择。已经确定观看方式并要转词，可接 `nai5-writing`；尚要落实镜头与空间，可接 `nai5-illustration-composition`；需要连续叙事则接 `nai5-comic-storyboard`。这些是按任务发生的接续，艺术表达也可以独立完成。
