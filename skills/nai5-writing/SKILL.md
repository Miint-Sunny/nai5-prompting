# 通用提示词写法与精确改词

承接用户已定内容，按 [写法契约](references/conventions.md#writing-conventions) 选择本次终点；共同语法、预设、用户事实与原串保护只在此确立。普通完整画面再读 [普通写法](references/illustration.md)，用户限定了修改范围（一处或多处）时按 [精确修改](references/conventions.md#writing-exact-edit) 处理：范围外字符不动，连带改动只列不改，范围不清先问。来源核查按需读 [共享依据](references/sources.md) 的相关节。

漫画或四格的逐格编译由已启用的 `nai5-comic-writing` 补充，已定衣物片段及服装表达由已启用的 `nai5-costume-writing` 补充；当前任务需要时才读取，不默认全载。使用完整稿时直接读对应同名章节，无需另装技能。只有核心而缺少所需补充时，完成现有规则能支持的部分，说明专项规则尚未载入，不把普通模板当作已完成的专项交付。

转换保留已定剧情、镜头、服装与文字；缺少创作决定时只指出具体缺口，按本次需要接相应构思任务，现稿充分则直接交付，已有确认不再索要。完整字段、衣物片段和局改的范围分别遵循当前契约；不因某个示例或领域默认重写用户锁定内容。

此入口交文本。没有真实写入工具时，用户要求填工作台也只能拿到可填写内容，并如实说明未写入；纯文字修改不声称已执行设置或验证成图。
