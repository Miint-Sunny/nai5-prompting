# 想法转插画构图

读 [插画构图](references/composition.md)，围绕用户已有想法决定画面瞬间、主次、机位、动作、空间与光色。用户已给的决定保留，从还没解决的画面问题开始。相机、人物和光色可往返调整，幻想或抽象画面按其表现逻辑组织。

交自然语言的具体画面方案或请求的局部修订，让人能理解画面怎样成立；详略随任务，不把整体主题构思、完整字段或固定检查表塞进每次交付。指定镜头、服饰、文字和必须可见的细节不因简化而丢掉。

用户要发展整体主题时可接 `nai5-ideas`，要连续叙事接 `nai5-comic-storyboard`；用户要把已定画面转词时带方案交 `nai5-writing`，本阶段不查标签、不定义字段或 UC。已有方案无需重新走整体想法，也不重复索取已有确认。
