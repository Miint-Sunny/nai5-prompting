# 服装设计构思

读 [服装设计](references/costume.md)，根据角色、场合与本次审美目标探索轮廓、部件、配色、材质、穿法或道具关系。设计方法是开放工具箱，选择能表达当前印象的方式；幻想、舞台与日常可以有不同穿着逻辑，词库不限制创意。

用户给定的部件、数量、左右位置、颜色、材质、印字和已认可部分保留。角色资料只有实际提供或启用才使用，缺少 OC 库不阻塞，也不编造缺失身份或外貌。局部设计修改只交受改部分；主案或方案数量与详略按本次要求，不附固定模板或衣物提示词。需要来源时查 [参考依据](references/sources.md#costume-design.s12)。

完成本次设计就是可用结果。衣服已定而只要转词、衣物片段或精确原串修改时，直接接 `nai5-writing` 与 `nai5-costume-writing`，不重新设计；服装要用于插画构图或漫画分镜时，带已有方案继续相应任务，已确认内容不重复问。本包不加载写法字段、语法、UC 或其他技能来完成设计。
