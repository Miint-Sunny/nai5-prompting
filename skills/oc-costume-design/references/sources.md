### 视频：原片观点与本领域方法转化

| 来源 | 实际分析材料 | 主要吸收内容 |
|---|---|---|
| [Parion圆周率：《漫画家不会告诉你的20大技巧·分镜篇》](https://www.bilibili.com/video/BV1VT411K7RS/) | 归档记录：Av473572541 P1 的烧录字幕与抽帧漫画案例 | 00:12格面积/景别；02:48环境；03:40动作前后；05:20正反打与轴线；07:14连续蒙太奇的删格案例；09:40起不同连接方式；14:14起重复构图与跨时空连接 |
| [Parion圆周率：《漫画家不会告诉你的20大技巧·平面篇》](https://www.bilibili.com/video/BV19G411b7tB/) | 归档记录：Av429199208 P1 的烧录字幕、概览与完整帧抽查 | 00:08间距分组；00:52字距与字体；01:54起气泡与声效；04:26跨页；04:56起破格、插格和互动格；06:40起留白、无框、背景格、装饰与叠像 |

时间为归档材料的近似定位。**原分析依据烧录字幕与可见漫画案例，不是音轨听写或逐字转录。** 分镜篇01:04–02:12音乐比较未听辨，只核对标题、节奏图与后续字幕。非常短暂的文字可能未被采样捕获。

视频作者将内容定位为个人经验；本领域方法不把20条当作标准答案。尤其做了以下区分：

- 格子面积与镜头景别分开控制；格数与阅读速度不建立必然关系。
- 预示/关键/反应是可压缩、可省略的组织方式，不要求所有动作占三格。
- 连续叙事的删格会改变动机；有意义的静止、重复、空镜仍可保留。
- 版式与象征层不等于场景中的真实物体；心理黑底不自动成为夜晚，叠像人物不成为现场巨人。
- 作品案例用于理解演出功能，不把视频画面的作者当作用户授权的 NAI 画师串。

### 综合方法如何对应来源

| 技能决策 | 主要证据 |
|---|---|
| 意图→可见演出→阅读节拍 | 分镜篇；W2–W4；W7 |
| 事件顺序与读者得到信息的顺序分开 | 分镜篇连续/交叉/心理连接；W4的页数比较；G1 |
| 故事时间、阅读时间和情绪节拍分开 | 对两段视频的综合分析，结合W4/W7/W8；是本领域方法的整理框架 |
| 入口、重点、出口与气泡先行 | 平面篇；W1/W5/W6/W10 |
| 真正翻页后/屏下再揭晓 | W4；W8/W9；G1 |
| 全页版式、逐格可见内容、后期文字的作用域 | 创作阶段区分阅读布局与文字位置；接口字段和应用反馈另存写法来源 |
| 整页与逐格两条制作路线 | 保留完整阅读设计，再按制作环境选择；不是官方优劣排名 |

### 用户材料的叙事经验

归档《分镜脚本提示词（例）》支持“剧情节点—页级节奏—逐格镜头、文字和衔接”的制作顺序，以及避免没有作用的连续大头、让静默格有意义、页尾与下页协作等方法。它原来用于剧本改编，原件中的不新增剧情、续写位置和读向并非所有原创任务的要求。

归档反馈里，毯子边沿漂移、包的开合机构改变、连续持物丢失、灰阶明暗变化，分别促成当前的持续状态、道具结构与明暗连续性检查。这些是局部经验；完整提示词、全部设置与批量结果并不齐全，不提供成功率保证，也不称本轮重看了视频、图片或新增生图验证。
