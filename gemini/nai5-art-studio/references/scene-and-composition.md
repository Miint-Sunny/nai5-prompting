# 场景设计与插画构图

本文件涵盖两部分：**场景与情境设计**（让环境自身成为主体或承载故事的空间）与**单幅插画构图**（把想法落实为具体的瞬间、镜头、人物关系、动作力学与光色）。

---

## 第一部分：场景与情境设计

从一个地方怎样存在、平时怎样被使用，以及它给观者什么空间感受出发。场景既可以作为人物活动的舞台，也可以独立成为无人物或小人物尺度的完整画面。

<a id="ideation-scene.subject"></a>

### 1. 抓住环境的核心看点

先确立这个地方最吸引人的一组空间关系：

- **尺度对照**：庞大建筑结构与细小的人类使用痕迹（如巨型水闸下狭窄的巡检步道，人物只作尺度参照）。
- **秩序与偏移**：整齐重复的阵列中出现局部变化，或明亮表层下露出幽暗通道。
- **取景尺度选择**：大远景适合交代地形走势与建筑群呼应；中景适合看清人如何进入、停留和使用空间；近景局部（磨亮的木柜边缘、刚修补过的石槛、积着雨水的凹槽）能借触感与痕迹让人想见整个场所。

<a id="ideation-scene.life"></a>

### 2. 从运行与使用方式长出空间

想清楚这个场所日常如何运转，再把过程变成可见的路径、开口与陈设：

- **动线与摆放**：人从哪里进出、物品怎么运送、何处作业、何处休息或收纳？例如街坊修理铺会把常用工具挂在伸手可及的工作台后、门边留出等候凳；高塔维修工坊则会围绕中央升降竖井分层布置平台与吊索。
- **生活痕迹**：痕迹不必等于破败杂乱。新建、整洁或精心养护的场所同样有使用逻辑（如擦拭干净的玻璃柜台、按尺寸排好的器皿）。
- **幻想规则推演**：架空场景顺着核心设定推演日常后果。例如若物品会朝光源缓慢漂移，储物架就会设在背光墙面、窗口加挂遮光帘。

<a id="ideation-scene.space"></a>

### 3. 建立空间层次、时间与材质相互作用

- **边界与纵深**：用门框、转角、栏杆、地面光带或高低差引导视线；需要通透感时让近处入口、中景通道与远处目的地连成可辨路线；需要幽深或迷失感时，用重复门洞与近景遮挡截断视线。
- **时段与天气的具体后果**：不只贴「清晨」「雨后」标签，而是写出此刻的变化——早班前哪一排灯先亮、雨刚停时石板路哪处还积着反光而棚下已经干爽、微风吹起哪一侧的帘布或草叶。
- **材质与光感**：厚石墙窄窗只照亮内侧一道窄边，湿木板把暖灯拉成狭长反光，薄金属牌在风里微翘。用材质受光后的表现配合空间冷暖，营造可停留或疏离的氛围。

## 第二部分：单幅插画构图

围绕已有想法决定画面定格在哪一瞬间、第一眼看哪里、相机怎么拍、身体与物件如何接触，以及光色怎样统合画面。

<a id="ideation-composition.view"></a>

### 1. 镜头、空间与视觉主次

先问「观者第一眼应当看见什么」，再协同调整景别、机位高低、观看角度、遮挡与主体占幅：

- **机位服务看点**：要强调高耸感可放低机位（`from below`）让结构向上延伸；要看清桌面铺陈、野餐垫或双手分工，可从斜上方微俯拍（`slightly from above`）；要营造窥视或静谧感，可用门框、树枝或近景器物做前景遮挡。
- **取景匹配可见部位**：必须看清全身姿态、走路或坐卧地面时给足全身取景（`full body`）；重点在神情与手部细微动作时用半身或近景（`upper body` / `cowboy shot` / `close-up`）。若用户指定必看的细节与当前景别冲突，主动指出并调整取景，不静默裁掉用户要求的细节。

<a id="ideation-composition.action"></a>

### 2. 动作瞬间、身体承托与可见后果

避免空泛地写「在互动」或把连续多步动作（拿起、转身、跑开）硬塞进同一个静止身体：

<a id="ideation-composition.action-moment"></a>

1. **选定最具表现力的冻结瞬间**
   - **起势（将动未动）**：用视线、伸出一半的手和与目标的距离表现意图或犹疑；
   - **进行中**：用身体倾角、迈步重心与衣发扬起方向表现动态；
   - **接触瞬间**：突出握手、递接、按压或倚靠的受力点；
   - **收势与余韵**：用停下的姿态、散落的物品或放松垂落的肢体表现刚刚发生的事。

<a id="ideation-composition.action-body"></a>

2. **从受力与支撑安排身体和物件**
   - 侧躺、倚靠、托腮、持物或双人接触时，先确定**承托面或被接触对象**的位置与朝向，再安排手肘、手掌、膝盖或背部如何落上去。
   - 分清「轻轻搭着」「用力握紧」「撑住身体重量」与「刚碰到边缘」的区别，让躯干倾转与四肢张力符合重心。近景画面用手臂入画方向和接触位置交代归属。

<a id="ideation-composition.action-effects"></a>

3. **推导动作带出的物理与环境响应**
   - 动作或微风带起哪一侧的发梢、衣摆、长耳或丝带？身体压在野餐垫、沙发或草地上是否留下微陷的褶皱？
   - 检查当前镜头能否清楚拍到关键接触点与肢体轮廓；若重叠遮挡导致动作难懂，微调观看角度或肢体间距。

<a id="ideation-composition.light"></a>

### 3. 光色与多视图版式

- **光影组织**：明确主光方向与性质（如树荫漏下的斑驳午后暖阳、室内冷屏幕光配门缝暖光）、受光边缘与暗部补光。
- **分格设定图与多视图（非叙事漫画）**：表情集、服装三视图或相册拍立得拼贴等静态展示，可采用「一张主全身图 ＋ 若干局部细节小图」或对齐色块/网格编排；若有标题或标签文字，预留不遮挡脸和手部关键细节的文字区域。需要连贯时间叙事时则转入 [漫画架构与分镜](comic-storyboard.md)。
