# 整体想法与艺术表达

本文件涵盖两部分：**整体想法构思**（寻找主题、故事种子、关系切入点与无题即兴构思）与**情绪、象征与艺术表达**（把感受转化为观看关系、节奏留白、媒介笔触与超现实形式，以及拆解参考图风格）。

---

## 第一部分：整体想法构思

先想值得展开的内容：想表达什么、谁处在什么处境、哪种关系或变化让人记住。想法可以从人物、情绪、世界规则、矛盾、声音、物件、梦境或形式实验出发，不必在构思起点先受限于现成标签或提示词模板。

- **按需交付**：用户要一个点子就深入打磨一个扎实方案；用户要对比方向时，再提供有真实体验差异的多个选项。只要求点子、故事种子或梗概时，交付到该阶段即可，不默认附镜头表或提示词。
- **从尚未决定的地方开始**：已有主题就顺着主题推进，已有故事就只处理未定的关系或落点；资料不足时先用已知信息给出具体主案，将新增设定标明为建议，仅在缺口直接影响用户核心意图时补问。

<a id="ideation-ideas.explore"></a>

### 1. 找到有记忆点的核心

可顺着当前题材从以下切入点试探，而非逐项填表：

- **关系与反差**：谁依赖谁、误会了什么、原本熟练的习惯在什么场合突然失效？熟悉的人或物进入不相称的环境会产生什么反应？
- **愿望与取舍**：角色想要什么、为什么没有直接拿到、当下做出的微小选择透露出怎样的性格？日常或抒情小品无需硬塞危机。
- **规则与例外**：把世界里的一个日常常识改动一处后，生活细节会怎样随之改变？保留可理解的日常后果，让奇想自带内在逻辑。
- **感官与情绪**：从温度、声音、材质触感、空旷感、压迫感或亲近感出发，寻找最能承载它的具体情境，而不是先堆砌背景装饰。
- **物件与母题**：一件物品如何改变两人的距离，或在不同时刻呈现不同含义？物件也可以纯粹承担审美焦点，不必都设计成机关。
- **形式与观察视角**：把事件交给不常见的观察者，或借书信、物件使用痕迹、相册前后对比、梦境、并列日常来组织——按「希望观者先看见什么、暂时留白什么」来选定载体。

### 2. 用户没给题目（「随便画」或只给角色没说画什么）

按画师做自由单图的方式推进：

1. **先抓一个具体的小起点**：一件日常物品、一个细微动作、一句话或一个词，不先从宏大场所或空泛气氛起手。
2. **对它做一次明确变化**：
   - 把两样不相干的东西组合在一起；
   - 把它放进不该出现的地方；
   - 改变尺度（变极大、变极小）或置换材质；
   - 换一种非日常用途，或取字面意思开个视觉玩笑；
   - 推想它发生前一刻或刚结束后的现场状态，或把常规预期倒过来。
3. **从点子长出画面**：谁在场、在什么位置、什么时刻、什么光线都围绕这处变化服务，气氛最后自然浮现。
4. **目视自检**：在心里只看画面本身——观者不读文字解释，能不能一眼认出点子所用的那件核心物品、看懂变化发生在哪里？如果物品容易被画成别的东西或看不出变化，就换一个更直观的起点重想。
5. **长相留白与单案推进**：用户没给人物外貌（发型、发色、瞳色）时，构思与后续写词都不自行编造长相；确定一个好点子后直接把它做深，只交一个主方案，开头先用一句话点明这张画的核心画面。同一会话再要一张时，换用新的起点与变化方式。

<a id="ideation-ideas.character"></a>

### 3. 角色事实与创作弹性

- **版权角色**：不熟悉且有检索工具时，先核对角色外貌结构、性格职能、背景与常见造型。核对资料是为了理解角色，而非把全部百科设定塞进一张图；反差、AU、换装、玩梗或有意 OOC 都是合理的创作选择，只需分清「有意改变」与「无意记错」。
- **原创角色（OC）**：使用已有 OC 时以用户提供的设定为事实，在本次开放范围内发挥；用户要求从零设计新 OC 时再大胆提出身份、性格与外貌提案（可接 [角色与服装设计](character-and-costume-design.md)）。

<a id="ideation-ideas.compare"></a>

### 4. 让比较方案有真实区别

用户需要多个方向对比时，改变核心体验或关系（例如：换另一人的视角、从冲突前夕改为事后余韵、让环境反过来主导人物、把直接揭晓改为含蓄留白），并简短说明各案的看点。若用户只要求配色变体或局部微调，就只改指定维度。

## 第二部分：情绪、象征与艺术表达

具象、写实与风格化画面均可通过空间关系、光色节奏与媒介笔触强化情绪和艺术感；抽象与超现实是可选方向，不默认把用户的具体场景抽象化。本阶段聚焦视觉感受、形状组织与观看体验，不把艺术方向简化为画师串或标签堆砌。

<a id="ideation-art.feeling"></a>

### 1. 把情绪转化为可看见的关系

情绪往往体现在方向、距离与停顿上：

- **身体与视线的张力**：想要靠近却有所保留，可以用前倾的身体配回避的视线；已经结束却不愿离开，可以用收拾好的行囊配仍停在门边的脚步。
- **空缺与在场**：例如表现「仍为离开的人留着位置」，可以让整张餐桌堆满日常杂物而唯独留出一席整洁，也可以只让一束余光落在对面空椅背上。前者偏向日常叙事，后者偏向安静余味。
- **非冲突情绪**：愉悦、丰盛、慵懒或纯粹的感官舒适同样能支撑完整画面，通过轻快的色彩呼应、舒展的姿态或温和的材质对比即可成立，不必强行制造苦痛或戏剧冲突。

<a id="ideation-art.metaphor"></a>

### 2. 让象征在画面内发生具体联系

象征不是给抽象概念贴通用图标，而是让物件与人物动作、场所或时间产生具体作用：

- 先问这件物品为什么在本题承载意义，再通过**尺度、位置、累积变化或缺失**表现出来。
- 例如表现「寄不出的信」：可以让未寄出的信封越叠越厚、挤占桌面仅存的书写空间（突出累积的负担），也可以让一大张空白信纸占满桌面、字迹只停在称呼之后（突出停笔的空白）。
- 用户已指定象征物时，围绕该物品设计位置与互动关系，不擅自替换成其他符号。

<a id="ideation-art.rhythm"></a>

### 3. 用密度、节奏与留白引导视线

关注观者第一眼落向哪里、随后滑向哪里、在哪里停留：

- **疏密对照**：密集纹理围出的小块空白像喘息之处；主体贴近画框一侧、面朝方向留出连续空白，能拉开未抵达的距离或等待感。
- **重复与偏移**：等距排列的窗格、柱列或台阶中，只要有一处光影、姿态或开合发生微小偏移，就能在不依赖剧烈动作的情况下建立焦点。

<a id="ideation-art.unreal"></a>

### 4. 抽象与超现实的成立条件

- **抽象提取**：从真实感受中提取运动节奏、疏密密度或冷暖色块关系，让形状和色彩本身成为画面主体，无需在最后硬塞一个写实人物做解说。
- **超现实推演**：先选定一处有意味的规则变化（尺度倒置、材质置换、空间折叠、时间并置），再写出它在画面上的**可见物理后果**。例如房间随记忆折叠时，墙角形成明确折线，桌面、门框与窗光都沿着同一道折面偏转，让观者看清「异常发生在哪里」。

<a id="ideation-art.form"></a>

### 5. 媒介、形状语言与笔触作用

先确定画面需要怎样的表面与边缘，再选用对应形式：

- **边缘与线条**：连续细线适合表现克制或犹疑的轮廓；大块深浅平涂能压缩或拉开轮廓周边的空间；水彩式湿画渗化可柔化边界；粗粝干笔能保留速度与摩擦感。
- **具体做法代替空泛风格名**：提出水彩、版画、拼贴、厚涂或赛璐珞方向时，明确说出本图要用的是透明叠色、压印错位边缘、纸片撕接层次还是高对比硬阴影，让视觉方案直接服务后续构图或写词。

<a id="ideation-art.reference"></a>

### 6. 拆解参考图的视觉做法

用户提供参考图要求分析风格或借用表达时：

1. **先记客观可见的组织方式**：明暗大块分布、冷暖色是相邻碰撞还是大面积统调、轮廓线何处清晰何处消融、笔触相对人物的比例、前后景是拉开纵深还是压在同一平面、细节集中在哪些部位。
2. **区分借用层级**：分清用户是想借用参考图的光色氛围与媒介笔触，还是要沿用其构图骨架。独立新图只吸收光色与形式语言，重新设计人物动作与空间；仅在用户明确要求按原图构图改画时才保留原构图。
