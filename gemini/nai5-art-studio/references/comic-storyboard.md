# 漫画架构、布局与连续性

本文件用于漫画（含四格、页漫、条漫）的故事导演、页格排版、连续性管理与完整文字分镜交付。

- **阶段起点与终点**：
  - 用户只要故事点子或段落架构时，交到梗概与揭示顺序为止。
  - **完整新漫画、续写新页或未经审阅的新增剧情**，先按本文第四部分的**三部分完整文字分镜**交付并等待用户反馈；即使首次请求提到最终要 NAI 提示词，也先交分镜审阅。
  - **明确跳过审阅的例外**：当用户明确说「直接给词」「只要提示词」「不用分镜」「直接能用的」时，直接转入 [漫画提示词编译](writing-comic.md)，在同一轮先给一份逐格简稿（一格一行，注明为本次补足），紧接着给出完整提示词导出。
  - 已有定稿分镜、用户确认分镜后，或针对已要求提示词的分镜给出明确修改意见时，落实修改后直接转入 [漫画提示词编译](writing-comic.md) 出词，不再多加一轮确认。

## 第一部分：故事导演与节拍拆格

<a id="comic-director.s01"></a>

### 1. 一句话锁定故事任务，分开「事件顺序」与「揭示顺序」

先用一句话明确：**谁处在什么局面，什么可见事件改变了局面，本页/本篇停在哪里。**

- 短篇故事可用「目标 → 阻力 → 选择 → 结果」；日常或四格小品可用「常态 → 细小偏移 → 被注意到 → 反应或余韵」，无需强加危机或套用神秘纸条模板。
- 将心理活动转化为可见演出（眼神、距离、手部松紧、道具状态变化）。
- 区分**实际发生了什么**与**读者在哪一格才看见什么**：记录角色此时知道什么、读者此时知道什么、哪样关键物暂时被裁切或遮挡在画外。后续要操作的部件（如包的拉链、桌上的便条）须提前存在于设定或前格中，不凭空突变。

<a id="comic-director.s03"></a>

### 2. 按阅读节拍拆格（每格冻结一个可读瞬间）

一个节拍是读者完成一次认知、情绪变化或停顿。**每一格只冻结一个清晰的动作瞬间**，不把「伸手、抓起、转身、跑走」塞进同一格的同一具身体里。

| 格子职能 | 回答什么问题 | 常用画面安排 |
|---|---|---|
| **建立** | 在哪、谁与谁、当下处境 | 交代空间关系的全景、中景或有代表性的局部 |
| **预示** | 什么即将发生变化 | 手接近开关、脚步入画、视线突然转移 |
| **关键** | 变化发生在哪一瞬 | 接触点、表情骤变、关键物件露出 |
| **反应** | 变化对角色意味着什么 | 眼神停留、手指收紧、身体微退或放松 |
| **停顿** | 为什么迟疑、等待或沉默 | 静止的手、空镜、同机位下的细微姿态变化 |
| **揭示** | 哪个悬念得到解答 | 镜头转向遮挡处、拉远露出全貌 |
| **余韵** | 事件留下什么感受 | 新的共同动作、改变后的物件状态、安静空镜 |

拆格后做三项检查：
- **删格检查**：删掉这一格是否会破坏因果、动机或必要停顿？若无影响则合并或删减。
- **强调检查**：大格与特写是否给在了真正重要的变化或揭示上？
- **镜头与背景分配**：避免每格都塞满全部人物和整间屋子。建立空间或收尾大格给足背景；中间的反应格、手部格、道具格只留桌面边缘或门框等必要接触面。只写当前镜头内实际可见的身体部位（脸部特写不写鞋裤，手部特写不写发型）。

## 第二部分：页面布局、破框与文字占位

<a id="comic-layout.s01"></a>

### 1. 默认读向与版式

- **默认阅读顺序**：从左往右、从上往下（右→左仅在用户明确指定或改编日漫原作且要求右读时使用）。
- **四格漫画默认版式**：未指定版式时，**四格默认采用 2×2 田字格**，读序为「左上 → 右上 → 左下 → 右下」；竖排单列（1×4）或其他排布仅在用户明确指定时使用。
- **色彩默认**：新漫画未指定色彩模式时**默认全彩**；黑白或半黑白（仅头发与眼睛保色）按用户指定启用。
- **条漫（Webtoon）**：按手机竖屏滚动视窗编排，利用纵向间距控制停顿与屏下揭示，避免横向并排过多窄小画格导致人脸与文字过小。

<a id="comic-layout.s03"></a>

### 2. 区分裁切、破框、跨栏与无框前景覆盖

| 手段 | 定义与导演阶段须写清的要素 |
|---|---|
| **画外／裁切** | 身体在取景框外；大场景中「只伸入一只手」必须有合理的画边裁切或遮挡来源，不能在无遮挡俯视全景中让其余身体凭空消失 |
| **角色破框** | 某格人物的一部分越过本格边线；写清**阅读目的、躯干/关节来源、越过哪条边进入哪块留白、仍属同一瞬间**（不能跨进下一格抓东西） |
| **跨栏画格** | 单个画格横跨两栏或全宽，仍只算一格；写清起止位置与读序 |
| **前景覆盖人物（Overlay）** | 一个完整连续的无框人物影像叠在若干底层画格前方，**底层画格延续到人物背后、格线在人物轮廓处被遮断**（不是在旁边另开一个独立大格）。写清覆盖位置、所跨底层画格、所属时刻与阅读次序，并让底层画格的关键脸部、动作与气泡避开被遮挡区 |

<a id="comic-layout.s06"></a>

### 3. 文字与声效从分镜阶段占位

- 区分五类载体：**对白气泡**（说话者、原文、先后与尾巴指向）、**旁白框**（Narrator box）、**内心话**（thought bubble）、**拟声词**（声效字、声源与位置）、**道具文字**（写在纸条、标牌、屏幕等实体上）。
- 开放创作时可主动配合动作与气氛安排简短贴切的对白或拟声词；忠实改编、冻结原文或静默格则严格保持边界。**静默格直接省略文字项**，不写「本格无文字」之类的否定句。

## 第三部分：身份与状态连续性

<a id="comic-continuity.s01"></a>

1. **五层连续性记录**：
   - **身份**：发型、发色（及灰阶模式下的明暗深浅）、瞳色、体型、种族特征与标志配饰。
   - **本场服装**：领型、袖长、层次、下摆与颜色。切到短袖后，手部特写只写裸露前臂，不残留长袖袖口。
   - **道具固定结构**：首次出现时固定包型、开合机构（如拉链包 vs. 按扣包 vs. 敞口包）与提手数量，后续格只改开合状态，不临时换机构。
   - **逐格持续状态**：每一格既写**本格新动作**，也保留**此前已成立且当前仍入镜的状态**（例如前格右手拿钥匙、本格左手拿杯子且双手入镜时，必须写明右手仍持钥匙；毯子覆盖高度在跨景别时保持在同一身体锚点，除非安排了掀开或滑落的动作）。空手直接写「空着的左手」，不列举没拿什么。
   - **空间锚点**：换机位时用门边、桌角、窗框等必要地标维持空间方位感。
2. **色彩模式与原色分离**：
   - 角色的原始配色留在设定记录中；选用**半黑白**（默认仅头发与眼睛保留原色，其余人物、衣物、道具、环境与光效全转灰阶）或**黑白**（全去色相，保留 `pale`/`dark` 等明暗对比）时，分镜与后续提示词按实际画面应显示的颜色与明暗描述，防止跨格深浅颠倒。

## 第四部分：完整文字分镜的三部分交付格式

当任务需要交付完整文字分镜时，按以下三部分输出：

### 一、剧情结构与必须保留的节点
- 说明起点、人物关系与目标、核心转折与落点，列出必须保留的用户设定、指定事件、台词原文与关键道具。

### 二、建议总页数、分格数及每页核心内容
- 给出总页数、每页格数与总格数（与第三部分逐格稿严格一致），简述每页的节奏重点与页尾承接。

### 三、完整逐页逐格文字分镜
逐页逐格写明（使用位置与大小称呼画格，如「左上格」「顶部全宽格」，审阅序号仅作辅助）：
- **格位与大小**：所在行组、方位、相对大小（若有破框或前景覆盖，单独标明跨越范围与阅读次序）。
- **景别、视角与空间**：镜头远近、高低角度、可见背景锚点、人物左右站位与实际入镜部位。
- **瞬间动作与持续状态**：本格冻结的新动作、表情视线，以及仍在镜头内的既有持物或覆盖状态。
- **文字与载体**：对白气泡、旁白框、内心话、道具字或拟声词的原文与归属（静默格直接省略此项）。
- **格间衔接**：与下一格或下一页的视线、动作或悬念承接。
