# OC 角色与服装设计

本文件涵盖三部分：**OC 整体角色设计**、**角色服装与衣橱设计**，以及按需使用的**时代与原作背景资料核对**。

---

## 第一部分：OC 整体角色设计

围绕角色为什么值得被记住，发展其内在核心、世界关系、可观察行为与视觉辨识度。

- **从零设计 vs. 已有 OC**：用户明确要求从零设计新角色时，可主动设计身份、性格、外貌与服饰主案；使用已有 OC 时，以用户提供的设定为唯一事实，只发展本次开放的部分，不替已有角色臆造过去或改写锁定特征，也不把单次换装自动写回永久设定。

<a id="ideation-character.core"></a>

### 1. 角色核心、世界关系与外在行为

1. **能生出选择的角色核心**：不只贴「温柔」「高冷」等形容词，而是明确角色在意什么、习惯怎样解决问题、在什么事上固执或退让。角色魅力可以来自专注、耐心或独特的生活志趣，不必强行给每个角色安排沉重创伤或黑暗秘密。
2. **与生活环境的互动**：角色在哪里生活、靠什么维持日常、随身工具怎么携带？例如狭窄通道作业的角色把工具贴腰收纳，或偏爱携一件过大的器具而养成侧身过门的习惯。
3. **把性格转化为具体行为**：放进日常小处境中衡量——接过意外礼物时手怎么放、计划被打乱时先看哪里、与熟人和陌生人保持多远距离。静态立绘从中选取最贴合气质的姿态。

<a id="ideation-character.identity"></a>

### 2. 外形辨识与可变化造型系统

- **远看轮廓，近看细节**：通过体型比例、发型或非人部位轮廓、主色块分布建立第一眼辨识度；即使换掉外层衣服，核心印象依然清晰。
- **区分本体特征与当次装束**：将长期不变的身体/发型/瞳色/标志物，与单次场合的外套、庆典服、雨具或临时状态分开管理。
- **按需交付**：需要完整角色设定时交「角色核心 ＋ 行为特点 ＋ 外形辨识锚点 ＋ 基础造型」；只要外形概念或局部重设计时直接交对应部分，不为凑字数补写长篇传记。

## 第二部分：服装与衣橱设计

设计贴合角色气质、场景功能或审美意图的服装。

<a id="costume-design"></a>
<a id="costume-design.s02"></a>

### 1. 建立设计简报与轮廓层级

先从已有资料提取约束（未知外貌不编造），浓缩为一句设计命题：

> 为【身份与性格】的角色，在【世界与场景】中设计【服装原型】，通过【轮廓／材质／图案】表达【核心印象】，同时满足【动作或身体约束】。

动笔细化前先定四件事：
1. **一眼可读的服装原型**：制服、礼服、工装、猎装、祭服、运动装、街头装、家居服等。
2. **轮廓重心**：量感落在头肩、胸腰、胯部还是腿脚？宽窄松紧对比是否贴合角色气质？
3. **主次面积层级**：主形（外套/主裙/连体装）、次形（内搭/下装）、强调点（领结/腰封/标志配饰）主次分明。
4. **身体与幻想特征避让**：检查帽兜、高领、宽袖、长靴与发型、四肢动作的关系。**翅膀、尾巴、角、兽耳等幻想特征默认遵循二次元视觉逻辑**，作为轮廓锚点保留，默认不为它们加画衣服开洞、分片、系带或防穿模加固边（仅在用户专门把穿戴接口作为设计看点时才展开）。

<a id="costume-design.s05"></a>

### 2. 服装设计工具箱（按需选用，无需全套叠加）

| 方法 | 适用问题 | 具体可见操作示例 |
|---|---|---|
| **服装与异质配件搭配** | 衣服简洁，靠直观反差立住身份 | 普通雨衣配长柄巨型镰刀；街头装搭王冠与巨剑，协调比例与配色即可成立 |
| **跨风格单品组合** | 靠穿搭关系改变整体气质 | 复古立领衬衫 ＋ 运动短夹克 ＋ 工装裤，用长短与色块统合 |
| **剪裁与结构重组** | 让主单品自身拥有新颖轮廓 | 连帽外套融合水手领宽翻领；围裙系法融入外层半裙 |
| **材质或工艺转换** | 保留熟悉版型，改变触感与正式度 | 用柔软粗针织做军装分割短外套；礼服金线刺绣落在帆布口袋上 |
| **比例与尺度变化** | 用少部件做出可爱感、力量感或重心 | 超宽大上装对比紧凑短下装；娇小体型背负轮廓清晰的巨型器具 |
| **穿法与场合错位** | 借穿着状态体现随性、疲惫或亲近感 | 正式衬衫卷袖松领口；严谨制服外披松垮居家针织开衫 |
| **图案与形状转译** | 让角色母题融入裁片而非只挂饰品 | 兔耳长弧线转译为成对长口袋盖；花瓣波浪用于多层裙摆边缘 |
| **单一风格内做减法** | 风格已对路，提升高级感与耐看度 | 删去争抢焦点的零碎挂件，拉开领口、衣长与主辅色块的比例 |

<a id="costume-design.s06"></a>

### 3. 组装服装系统与衣橱换装

- **从上到下拆解**：基础原型 → 主角单品 → 支撑内搭（领型/袖型/腰封） → 下装与腿脚系统（裙裤长短比例/袜/鞋靴） → 标志配件与开合收纳（扣、拉链、系带、背带位置）。
- **配色与材质对比**：采用「主色 ＋ 辅色 ＋ 少量强调色」；优先建立一组鲜明材质对比（如挺括硬皮革对比聚褶软针织、哑光棉布对比高光金属扣）。
- **衣橱换装（不变量 vs. 变量）**：固定角色代表色、物种特征与核心母题（不变量），调整服装原型、季节厚薄、裙裤比例与正式度（变量）。

<a id="costume-design.s09"></a>

### 4. 根据出图反馈迭代服装设计

用户发来成图要求调整服装时，先对照原设计稿区分是「提示词表达问题」还是「设计本身需要改」：

1. **轮廓不对**：调整衣长、宽窄量感与分割线，或更换基础服装原型。
2. **气质不符**（如想要可爱却显得生硬沉重）：把硬折角、笔直分割与沉重金属件改为圆润轮廓、松紧反差与柔和边缘。
3. **复杂道具被画成柱子或怪状物**：改用几何特征更鲜明的标志性道具，或简化结构描述。
4. **背负／持握位置错乱**：明确肩扛、斜挎或手持的左右侧、接触点与朝向（如背带斜跨胸口、包落左胯）。

<a id="costume-design.s11"></a>

仅在交付服装设计方案时使用（不默认附带英文提示词；用户要转提示词时接 [服装写法与片段表达](writing-costume.md)）：

## 第三部分：时代、职业与原作背景资料核对

当用户要求考据真实历史年代、地域、职业流程或原作设定，且该事实会直接影响场景、角色或服装方案时，围绕具体疑问核对：

| 核对维度 | 落实到画面的具体关系 |
|---|---|
| **职业、组织与日常流程** | 谁使用该空间、工具与记录放在哪里、操作与交接动作怎样进行 |
| **器物、服饰、材料与技术** | 当时当地是否已出现、该身份能否取得、实际如何穿戴、携带或收纳 |
| **居住、交通与公共空间** | 动线开口、取放高度、照明条件如何配合人物当前的活动 |

- 区分**有据可查的史实/原作设定**、**合理推断**与**本次有意采用的架空规则**；发现用户要求与史实冲突时，指出受影响的具体物件并给出保留画面意图的最小调整建议。
